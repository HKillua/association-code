## 3. 候选配置和归因比较

原生输入、划分、Q64/cap128、20秒时间单位和参考监督与上面相同；encoder/decoder各6层、d128、8头、FF256、dropout.1，head_hidden64、gate_floor.001，FP32。全实例2,156,814参数；普通路径2,006,277，效用及同容量普通学习门控路径均2,105,929。参数统计来自既有实现核验，不重复跑尺寸检查。

用户已确认以下候选首次成本测量设计：各阶段LR1e-4、Adam默认betas(.9,.999)/eps1e-8、clip1；每轨none/prefix/suffix等概率，截去floor(n/4)但保留至少2点；teacher用单轨/正对物理监督+BCE。utility使用冻结教师的原生四属性训练std作误差尺度（std<1e-6置1），epsilon=.001，不用V拟合尺度。teacher/utility/四臂adapt种子20/21/22。四臂相同teacher/decoder起点、抽样与mask序列，固定s0身份分数和完整V上选定的一次阈值；预定阶段终点，不用不变的身份F1替融合挑权重。最终效用辅助身份训练不加进这一轮。该确认不批准100步开发量或其预算。

## 4. 费用：已知项、未知项与已批准的测量上限

参考的013旧实现只测了每阶段两个批次。按100/100/100/20和6次阶段验证乘算，训练＋一次margin校准＋阶段验证的已知项为**6.911–7.433小时**。另外还有完整终评（含第7次关联）、准备、17次durable checkpoint写盘、汇总和进程启动。新TFM冻结缓存收益尚无CUDA测量，不能直接减预算；两步min/max不是置信区间或完工上界。014未来提供的终评耗时也受分组大小影响，不能当所有模型的固定上界。

候选尚无真实CUDA步时。完整成本应计为：

`准备 + U_teacher×teacher步时 + U_utility×utility步时 + U_adapt×四臂适配步时之和 + 一次身份全V评分 + 四次物理评价 + 写盘/收尾`

每次物理评价仍重建冻结原生编码；不能只乘训练更新数。新阶段墙时包含采样和checkpoint/评价产物写盘，原history.step seconds仍只含train_batch与设备同步。CLI进程导入及最后大preparation/execution报告写盘可能处于trainer计时之外，正式交接必须用**外层进程硬限时＋实际退出码＋最终完整产物**共同验收，不把run.elapsed_seconds当全部费用。

**已批准候选一次最多2GPU小时成本测量。** 相比013的一份物理终评，候选要做四臂终评，因此预留较宽上限；2小时是资源上限，不是实测成本或保证完成时间。配置内7140秒，外层7170秒TERM＋30秒清理，总7200秒；单作业单卡，CPU4，一次无重试，可动态选兼容卡、允许共卡。准备、训练、验证、写盘和失败都算在内。失败保留进度和已完成臂，不重置预算接着跑。这是独立新增额度，不挪用014额度；等014终态后再发布独立交接，不在014运行中提前开下一轮，不需要再次询问同一配置/预算。

正式参考与候选的预算字段刻意留null。这样目前可以检查每个已提出的参数，却不会让一个没有测量依据的预算数悄悄成为可运行默认值。测完候选并收齐014成本后，给总费用与明确上限，再决定正式比较；可以并行准备两条线，不要求任一先跑出好分数。

## 5. 两张表、物理产物与成败判断

完整任务表比较TMTAFF时间适配参考和候选：关联P/R/F1、预测分组下全目标物理误差、覆盖/漏预测、已观测区/缺失区、错并拆分、参数与实际费用。单源、简单融合、真实身份分组单列诊断，不与需要预测身份的方法混排。

参考当前singleton=observed，只在单条轨迹的已有支撑输出；候选singleton=model_decode会输出全部查询。两者误差的有效域不同，所以同时报告各自全目标覆盖，并在**两模型共同有效且真值有效的同一批点**重算误差。交集比较不能替代全目标表，零共同点记无可比误差、不能填0。人口、输入、查询网格或真值不一致时拒绝直接比较；预测有效域允许不同并显式报告，不能以删掉难点来获得好分数。

机制表只比较候选四臂；固定身份条件下关联分数必须一致，重点是缺失区物理恢复与覆盖。所有场景导出真实预测/有效mask/参考/时刻/分组，离线比较给最多5个改善和5个恶化目标索引供案例核查；不会按结果重新选阈值。014原任务不增加导出或重推理，新的训练/测量提案使用显式`--save-predictions`。

导出目录为参考的`<run>/predictions`或候选的`<run>/<route>-predictions`，每场景NPZ与JSON包含实际指标使用的数组，索引只承诺列出的场景已写完。离线工具另外核对父任务COMPLETED、完整评价人口和顺序；中断产物可用于诊断，但不能充当完整比较。完成真实运行后从仓库根使用：

```bash
python tools/analysis/compare_physical_predictions.py \
  --left runs/<candidate-run>/plain-predictions \
  --right runs/<candidate-run>/utility-predictions \
  --method predicted --output runs/<new-comparison-directory>
```

完整系统表将左侧改为参考的`predictions`目录。输出`comparison.json`含两侧原有效域指标、共同有效点指标以及案例的原文件/目标行索引；不会推理、训练、修改阈值或读T_test。上述尖括号是待真实结果替换的路径，不是可直接执行的任务。

首个值得继续的证据是：效用臂在同样身份、采样和容量对照下有真实缺失区收益，覆盖没有靠漏预测变好，具体轨迹能解释收益与损害，额外成本合理。若没有，先报告负结果和机制失效位置，不追加模块或声称创新成立。首轮V结果只支撑继续研究的判断，T_test仍封存；海上近邻与原创性边界仍按既有文献审阅，不宣称首次。
