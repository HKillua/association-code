## 研究问题与筛选

上轮有 17 个门内已有真候选的错首选，以及 42 个没有新鲜真候选的错首选。固定首报距离比在高覆盖失败。新的信息可能在已有候选中消歧，也可能让真候选重新可用。仅等时钟会移除候选，精度变化须与覆盖损失一起看。实验估计下一条本片段报文到达时，新信息相对仅等时钟能否净增加正确关联，同时控制错误。

|思路|在当前协议能区分的问题|本轮取舍|
|---|---|---|
|等下一条真实到达的 Level1 行|同一时刻拆候选老化、查询更新、对侧续报和新进入，查净收益及代价。|选定，数据已具备，能归因。到达是一条新的成品行，物理信息独立性未知。|
|将身份记忆与状态新鲜度拆开|先核首报有没有曾见但超龄的真对象。扩寿命能恢复该类机会，也会引入假旧边。|记录上界分层，本轮保持 60 秒状态新鲜上限，后续独立比较。|
|局部联合指派与显式空配|在已有候选同刻争用时，固定代价与预算，可检验容量约束和拒配。|保留。新候选可用性尚待核，先不把联合求解与新增证据混在一起。|
|用对侧活动辅助拒配|同几何和同覆盖下考查年龄、源间隔与局部活动代理，是否能区分根本没有新鲜真候选。|保留。需要排除场景密度和采样周期混杂。|
|跨源关联待定时，逐秒发布单源状态|将局部身份、跨源合并和融合状态解耦，避免疑似关联立即污染状态。|需有可追溯暂定、确认和修订输出后再测。保持原首报记录，本次未估状态精度。|

本轮借鉴 S-ON58/59/60/64 的信息增加、确认等待与历史评价区分。沿用 E-ON5 的物理距离和冻结校正作为共同目标域控制。保留既有候选集及最简单的最近选择，以便定位信息增量。假设是新位置可提升同候选池首选，对侧真实报文可增加可用真候选。竞争解释是候选老化带来的表面精度、异步位置不一致和新假候选抢占。

## 固定数据与对照

- 原 Level1 冻结 T_core 0、3、7，完整 279 个 E-ON5 有向跨源出生。早期无标签平移估计截止 600 秒，出生严格晚于 600 秒，位置保持、对侧新鲜年龄 ≤60 秒、校正距离门 ≤4 km。首位精确并列或门内空时拒配。源批号只作等同。采用原始报告理想到达时钟，当前同刻事件全部先到。各场 E-ON5 校正候选数及 t0 正、错、拒计数核对。
- t0 为出生首报。唯一的后续决策 t1 是同片段严格晚于 t0 的第一条行，须同时满足 t1−t0≤30 秒及 t1≤7200 秒。30 秒取已审 10/20 秒典型报告间隔之间可解释的工程预算，7200 为本诊断行政终点。无 t1 时保留该出生。到 30 秒仍无报为超时，行政结束早于截止为右删失。没有临时放宽等待或跳过首条。t1 各臂只使用 ≤t1 的报文。报告连续等待和理想每秒网格差 `ceil(t1)−ceil(t0)`。网格差以 t1 快照估计，真实执行及网格间后来到的报文不纳入此诊断。
- C0 是 t0 时所有对侧新鲜键，先于 4 km 门。以下臂分别记录候选键及门内键，最近选择、阈值、校正不变。

|臂|决策时刻与数据|
|---|---|
|birth|t0 原首报，保存原结果并在 t1 仅作静态比较。|
|expiry|t1，双方都用 t0 位置和时间，C0 按旧时间自然过期。|
|query|t1，使用新片段的新位置，其余同 expiry。|
|peer_freshness|t1，使用新片段新位置，C0 用 t1 前实际最新时刻判 60 秒年龄，对侧坐标仍冻结为 t0。该臂是用于拆分续鲜作用的对照。|
|peer_position|t1，保持与 peer_freshness 同一可用键，对侧坐标更新为实际已到最新位置。|
|open|t1，位置同 peer_position，可纳入所有新鲜对侧键。分开计 t0 已见但当时不新鲜、以及 t0 未见的进入键。|

所有三场的候选、选择及各时间状态固定后才读 A-B 标签。只做一轮，零模型训练、零 V／测试／参考。仅输出聚合。当前臂间不使用关联表时间或物理速度、航向。

## 主要估计量、资源与解释规则

- 主要同一 t1 人口 `open−expiry`，按出生给正确、错误、拒配及各向转移矩阵。汇总和逐场报告，零分母标不可判。报告全 279 的 birth 计数及各 t1 臂的全人口正确／错误／拒配／无决策，另报 t1 匹配人口与原 birth 对照。保留出生正确、门内真但错、门外真但错、无新鲜真而错、拒配五组；记录各臂真机会、真入门，以及原无新鲜真的错误中是否曾见超龄、何时由新报恢复。无确认及右删失保留分母。
- 预定机制比较 `query−expiry`、`peer_freshness−query`、`peer_position−peer_freshness`、`open−peer_position`。区分由错误改正确、错误改拒配及新引入错误。后续可选的生产决策不从这几个臂中事后挑冠军。等待报告各场和汇总中位/P95、有效范围、名义网格差。统计为有限三场描述性对照，不把出生当独立重复。
- 主资格需至少两场有返回，汇总正确数净增 ≥5 且错误数不增加，相同条件下至少两场正确不降、错误不增。通过仅支持“继续研究实际新增证据”，不能替代与 birth 的覆盖、发布代价和端到端资格。若仅降错并同时降正确，按失覆盖；若新报没有净收益或增害，关闭固定预算直接晋级，保留有支持的局部机制和替代思路。无同刻决策或数据不一致时停止并记录。
- 本地 CPU 一次，独立 `online_observation/confirmation_probe.py`，标准库，复用在线原字段、分组时间及注册距离。终点为三场聚合原件、新候选与错误原因的核算及生成前后权限验证。已存在输出拒覆盖。软件检查需覆盖 t0/t1 同刻、边界、超时、右删失、固定候选、真正入场、后续行变动不改变已固定输出。事后接 record-experiment → squeeze-experiment → Mode C。
