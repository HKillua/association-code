### A′ 的固定函数与候选

对组内当前可用来源集合 A(q)，共享头输出 s_j(q)。正温度时

`w_j(q; τ) = exp(-(s_j(q) - min_A s(q))/τ) / Σ_{k∈A(q)} exp(-(s_k(q) - min_A s(q))/τ)`。

τ=0 定义为原共享 hard：只在最小分数来源间均分精确平局。候选提前固定为

`[0, 1/64, 1/32, 1/16, 1/8, 1/4, 1/2, 1, 2]`。

不连续优化、不按 V 加密网格、不引入不同场景/源的单独温度；候选温度并不等于固定混合比例。选择函数为当前训练范围内、首 anchor/首目标代表、位置 reference 有效且至少两源支持的 query 的实际球面位置 MAE。每 query 权 1，不按误差删点或裁尾；精确相同损失选候选清单中更早者。所有候选损失完整保存。0/1 支持 query 对所有候选完全相同，因此在固定覆盖下只用可作用人口选择温度，与加入这些常数项后的全人口 MAE 最小化一致。

恢复继续为源质量均分给本源当前支持原节点，再用原节点纬度均值和经度正弦/余弦合量恢复；不直接平均已经归一化的 source_states 角度。圆周退化、无支持回退、速度/航向保持 Mean、全部分组/输出有效性沿 133。源名只定义等价类，不作特征、不排序优先。函数对任意有限 K 成立，K=1 必为权 1，K=0 保留既定回退；K≥3 的性质只做软件检查，不能称真实多源泛化。

## 为什么必须把 base 与 calibration 一起隔离

**禁止做法：** 取 133 的全部原 OOF 分数，外层留组件 c 时用“其余组件的原 OOF 分数＋标签”拟合温度，然后宣称严格外层 OOF。其余组件 d 的原 OOF base 是在 T\{d} 上拟合，包含组件 c 的标签；因此温度训练输入存在经 base 参数传递的间接依赖。仅删除 c 的分数行不解决该问题。

**本草案采用完整的两层组件隔离：** 只隔离新的 Q head＋读出流程；历史 teacher、阈值、固定 WS 与数据开发历史仍不是外层独立训练，必须继续披露。

设原 T32 有 12 个组件 C。各场及组件名单沿 133/134 原 manifest，不重新抽样。

1. 对每个无序组件对 `{c,d}`，使用 `T\{c,d}` 的合法 10 维特征、原标签 `log1p(单源位置误差m/1000)`、每 query 总权 1/每可用源权 1/K，重新拟合一个共享 Q66 头。均值/方差、z 裁剪、二次展开、λ=1 和非截距正则完整复用 133。共 `C(12,2)=66` 个唯一新解析拟合；不重新拟合 LINEAR 或 SHUFFLED。
   实现须提供仅 Q 的求解入口：原 `fit_score_models` 一次会拟合三个头，不能调用 66 次后只保留 Q 而把实际 198 次拟合误报为 66；新入口须与原 Q 数学/小例结果绑定，旧 133 接口保持不变。
2. 同一 `{c,d}` 模型可为两个外层折复用：外层 c 的温度训练只用它在组件 d 的预测；外层 d 只用它在组件 c 的预测。模型训练没有用 c 或 d，复用不会传递外层标签。私有记录保存训练/排除组件及具体预测去向。
3. 对外层 c，汇集所有 `d≠c` 的上述内层留出预测，共覆盖外层训练的 11 个组件。只在这些 query 的 reference 上比较固定 9 个温度，选择 τ_c。外层 c 的 reference 不得进入 66 个相关模型、归一化、温度选择、停止规则或候选集修改。
4. 外层 c 的 base 复用 133 保存的 `leave_c` Q 头；其原 OOF 分数可直接绑定复用。它只用 `T\{c}` 拟合。将已经固定的 τ_c 应用于 c，之后才评价 c 的 reference。12 个外层输出拼成完整 T OOF 结果。
5. 最终全 T 温度 τ_full 使用原 133 的 12 组件 OOF 预测及全部合法 T 标签选择。这里全部 T 都是最终训练范围，不再把该校准训练损失冒充外层泛化结果。最终部署 base 复用原 133 `full` Q 头；τ_full 与模型/输入契约冻结后，才可能进入一次固定 V32。

新 Q base 标签与原 133 一致；calibration 的监督是每个候选恢复位置的球面误差，不使用 134 oracle α、最佳源角色、真实组纯度或未来 V 标签作模型输入。训练标签可以依任务使用 T reference，预测接口仍只接合法物理特征、固定 Q 参数、全局 τ 和支持/分组。

## B 的具体发展入口，尚不执行

A′ 的全局正温度保持排序；如果外层结果仍表明罕见高损害误选主导损失，下一问题应是排序风险目标，而不是继续调全局尺度。一个最小候选是**共享低维风险评分器**：保留合法每源证据与对称集合关系，所有来源共享参数；按 T 的实际融合误差或成对误选代价训练，与同容量的普通误差/无代价评分器分离。可以先用现有二次特征的 65 个非截距系数，再决定是否需要共享小 MLP，不能预设重网络有用。

如选成对风险路线，T 标签可为两个来源实际误差差的符号，权重来自绝对米差；训练输入是共享特征差，来源名、匿名角色、reference、真实组纯度和 oracle α 均不作输入。需要另行固定 K>2 的成对归一化、损失/正则、无代价控制、0/1 来源回退、严格 base/风险头/读出的嵌套隔离，以及有限优化步数。误差相关/直接融合损失也是候选，不能把这份文字当作已选 B 架构或预算。

三层质量判断：当前新颖性是**待验的目标域适配价值**，不是发明温度缩放；研究价值在于以低成本区分“已有排序的读出限制”和“仍需改变风险目标”；可归因性由单因素读出、完整折隔离和强 hard 对照保证到本设置。134 只证明条件空间与错误代价，未证明任何 B 可学习；本草案不新增实证编号、论文数或有效方法结论。
