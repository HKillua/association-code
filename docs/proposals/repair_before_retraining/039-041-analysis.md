# 039—041：时间变化恢复了，但补全收益仍有限

本地从四轮全部 **256 个场景 NPZ** 重算位置球面距离、速度绝对误差和圆周航向误差，并核对原始命令、配置、1000条训练历史及四场CPU动态记录。未加载模型、扫描原ZIP、训练或重选阈值。结果仍是候选的单片段补全开发评价，不是完整关联/融合系统成绩。

**结论：039确实消除了所测四场decoder逐层时间幅度衰减，但位置反而更差；040用少36.3%的参数获得接近034的结果；041速度MAE改善6.66%，却仍几乎不随查询时间变化。三项均不能据此宣布补全已解决，也没有证据支持把pre-norm与去BCE直接组合后开跑。**

- 四份预测的场景/片段/身份/来源/query/真值/mask/位置底座和支撑分区逐数组一致：64场、1635片段、104640查询，每属性81207个可评点；23433个无真值查询保留。没有只给某一臂删难例。
