# 038：候选decoder内部已出现持续的时间变化衰减

2026-10-20。本地pull至`3d5be43`，按research-workflow的实验深挖与Mode C回流整理；两路独立只读复核分别核查执行/数字和机制解释。**038是冻结034候选物理teacher的定位，不是baseline TCM训练或新方法成绩。**

结论：查询时间确实进入网络，但在当前034权重的六层decoder中，不同query之间的表示变化逐层显著减小；到输出头之前就已近常量。因此下一次改进优先针对decoder保留时间差异的路径。已经定位到现象所在环节，尚未定位到某个attention、LayerNorm、损失项或优化过程的唯一原因。

## 2. 时间变化在哪里变小

对每个片段，先沿全部Q64查询时刻去均值，再对query及128个特征维求RMS，最后在片段间汇总。它衡量同一片段内部随查询时刻变化的幅度，不混入片段间差异。

| 位置 | 86轨RMS均值 | 中位数 | 本层/前层逐轨比率中位数 |
| --- | ---: | ---: | ---: |
| decoder输入 | .528352 | .528026 | — |
| 第1层 | .418261 | .421155 | 79.43% |
| 第2层 | .114717 | .113756 | 26.63% |
| 第3层 | .029956 | .029811 | 26.27% |
| 第4层 | .009619 | .009457 | 31.98% |
| 第5层 | .002489 | .002306 | 24.25% |
| 第6层/输出头之前 | .000584 | .000498 | 22.25% |

**86/86片段，每一层都比前一层低。** 第2—6层持续衰减，不是最终输出头才突然变平。逐轨最终/输入比率中位为0.000944164，即变化幅度剩0.0944164%，约缩小1059倍；最少缩小382倍、最多2152倍。均值之比为0.001105636，约缩小904倍；两种口径不混称。

逐场最终RMS均值分别为.000540586、.000701649、.000609386、.000389762；两来源均值为9001 .000529264、9002 .000644423。保留最多变化的`290:9002:7`也仅剩输入幅度0.261697%；不是少数离群轨或某个来源独有。

输入PE的RMS均值.523214、支撑投影.080831，实际decoder输入.528352，说明时间与支撑信息确实传入。**这里的“下降99.9%”只能修饰变化幅度，不能写成丢掉99.9%的信息、精度或有效知识。**

## 3. 输出头是否还有问题

| 属性 | 输出头行范数 | 归一化动态投影ρ均值 | 未缩放残差时间std均值 |
| --- | ---: | ---: | ---: |
| 纬度 | .008536 | .093856 | .000005260 |
| 经度 | .007643 | .063979 | .000003331 |
| 速度 | .154490 | .150983 | .000159456 |
| 航向 | .007939 | .094655 | .000004738 |

逐片段复算满足：

`head_projected_RMS = hidden_RMS × sqrt(128) × head行范数 × ρ`

公式复算最大差异小于1.1e−19，浮点前向残差std与float64投影std的最大差异为2.66e−8。头并非零向量，也并非完全不读取hidden变化；速度头范数与投影比例更大，输出仍近常量。**不能把问题只归咎于最后一层输出头。**

ρ不是“有效信息利用率”。对于固定能量沿128维各向同性随机方向投影，均方比例的平方根参照为1/√128≈.0884；该参照仅解释维数效应，不是当前hidden随机各向同性的检验。不能把航向ρ≈.095直接当作异常正交，也不能因此断言head已经最优。位置/航向头从零初始化后已更新，范数小还涉及训练尺度，不能仅凭小范数确诊故障。

将每条轨的真实未缩放残差替换为全Q均值后，**预测本身的RMS差异**只有：

| 属性 | 86轨均值 | 中位数 | 最大值 |
| --- | ---: | ---: | ---: |
| 位置 | .586916米 | .324690米 | 2.292210米 |
| 速度 | .004610 | .003069 | .036574 |
| 航向 | .000496° | .000452° | .001048° |

这些不是误差改善或准确率。034完整V的另一项对照已经证明消去学习时间变化几乎不改变MAE；038进一步显示此变化在decoder内部已被压低。两者人口不同，且034使用近似底座后的圆周均值、038使用真实head的未缩放线性残差均值，不要求小数逐位相同。

## 4. 不能误读的地方

- 当前生产代码确实把query PE＋support输入decoder（`cooperative.py:550`），使用默认post-norm层（`:113`），然后线性头映射物理残差（`:564`）。尚未发现漏传时间或输出重构错误。
- LayerNorm沿单个query的特征轴归一化；本统计沿query轴去均值。两者不同，LayerNorm不会令这里的RMS自动等于1。缺少未中心化范数、各层增益、attention/FFN分支和梯度，不能断言某个LayerNorm是唯一原因。
- `native_memory`与`decoder_memory`的中心RMS相等，符合所有token加同一role向量后去均值会消去常量的代数性质；不说明role没有作用。
- 零残差速度底座是训练确定的`speed_reference`，本来恒定；它不是观测速度插值，不能说“观测速度被压平”。
- 部分经度的微小变化低于FP32物理输出分辨率，不能把输出差异0叫作数学上完全没有变化。
- 038沿用eval推理；没有证明训练时也存在同样幅度、训练量是否充分、BCE/物理梯度是否冲突。不能把候选现象套用到baseline的033/037。

## 5. 证据回流与下一步

对既有补全问题矩阵`MC-MTAD-XVIEW-20261018-v1`作增量记录，不把新假设倒写为原计划：

| ID | 类型/证据级别 | 当前结论与边界 |
| --- | --- | --- |
| P038 | 问题/DE | 034学习残差近常量、未胜过观测控制（034完整V）；需要恢复有用时间动态。 |
| F038 | 现象/DE | 038四场86轨的decoder每层都衰减query变化；此前只知输出平，现在定位到输出头之前。 |
| M038 | 机制/AI、部分支持 | decoder对时间差异的保留不足是当前输出平坦的直接线索；原因可能包括残差/归一化路径、attention平均化和训练优化，未区分。 |
| E038 | 证据 | 038逐片段原始JSON、复算脚本、代码路径；034全V误差与消动态对照。两者同一模型端点，不算独立训练复验。 |
| C038 | 连接点/待验证 | 优先检验decoder主残差路径的改动能否同时恢复时间变化和提高补全准确率。 |

**下一单因素首选：只把候选decoder改为pre-norm，保留encoder、六层宽度、输出头及其初始化、观测底座、全部loss/BCE、采样和1000步预算。** 当前每个子层为`LN(x + F(x))`，pre-norm变为`x + F(LN(x))`，让原查询表示沿加法主路径传递。已核本地PyTorch2.10源码及[官方参数说明](https://docs.pytorch.org/docs/2.10/generated/torch.nn.TransformerDecoderLayer.html)。这是一项针对当前现象的结构干预假设，不是038证明post-norm有错，也不保证分支不会抵消时间差异。

[Xiong等，ICML2020](https://proceedings.mlr.press/v119/xiong20b.html)的官方摘要研究了LayerNorm位置与初始化梯度/优化的关系；本轮只核官方摘要，未全文精读。它提供成熟机制背景，不证明MTAD上的时间衰减由同一原因造成；不能把pre-norm本身包装成原创贡献。

与直接给输出头增加query跳连相比，先试原有decoder内的归一化顺序，保持同容量及结构深度；直接query通路保留为竞争方案，本轮不同时叠加。也不直接减`num_layers`，该字段同时控制encoder与decoder，会一次改动两处。

后续实验应从头训练，与034保持相同预算及人口，比较完整V物理误差、观测控制、来源/支撑分层；层间RMS仅为伴随机制诊断。如果RMS增大但误差不改善，说明恢复幅度本身不够，不能宣布修复。若动态与误差同时改善，也只支持该修改包有效，不证明唯一训练根因。

**本轮交付为结果分析和下一改法建议；未改生产模型、未新增训练或READY任务。** 035及037已在隔离目录运行，不重领、不因038自动改变它们。无需重跑038或再做一轮相同激活检查。
