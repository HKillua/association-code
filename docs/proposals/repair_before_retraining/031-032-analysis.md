## 改善来自哪里，还有什么没有学会

A/B所有输出的速度标准差由.126变为13.276，但在每个片段内、相同有效query上的速度标准差中位只有 **.000479/.005494**，目标为 **13.0638**。B主要学会了给不同片段不同速度，仍没有恢复片段内部的时间变化。总体方差增加不能写成动态建模成功。

探索性按目标速度分层：低于40的69448点占85.52%，MAE从24.007降到10.043；其余11759点则从61.856升到76.933。前者贡献总体MAE变化−11.942，后者+2.183。目标≥200的577点仅占.71%，却贡献A/B平方误差的95.90%/97.49%；这是≥40的子集，不能重复相加。以上只是解释原结果的分层，没有筛掉极值、改单位或据V重新拟合；也不能把低速区改善概括为全速度范围都改善。

据此收敛后续设计：

- **补全小创新：** 以观测状态和时间支撑为条件学习残差。先把航向底座＋圆周残差作为独立因子，在同一log速度坐标下与032比较；不要同时更换目标、采样和速度底座。速度的支撑外端点保持很差，时变残差仍需处理；不强制9002观测点残差为0。这是待确认的核心方法方案，尚未实现或训练。
- **关联主要创新：** 继续共享场景偏差与未知对应相互修正。既有四场留身份校准oracle只证明有信息可利用；真正机制必须用预测对应估偏差，推理不读identity/reference。固定补全，比较无校准、普通一次校准、迭代修正，防止把真值配对收益当算法收益。031/032不提供关联进步证据。
- **融合主要创新：** 时间与属性恢复效用有明确动机：同一来源在不同属性、支撑区域的可靠性不同。先固定相同正确身份分组，比单源、均匀融合、身份置信度权重、时间/属性效用，再接同一套预测关联；所有组使用同样校准结果，避免把校准收益再算一次融合贡献。以上是机制与消融设计，不是已成立的创新点。
