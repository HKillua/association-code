## 本轮综合判断

[049参考TFM已完成并复算](049-analysis.md)：358个多片段目标、22912个预测位置在300步完全相同，100步已近常量；42个恰两片段组也失败。共同17062点位置MAE63791.83m vs普通1797.14m，64场全差。标签顺序、mask、微批累计和冻结路径暂未发现可直接解释的错误；优先用现有快照定位条件信息在哪层消失，不先加步或JOINT。不能据此宣称论文方法本身无效。

[051符号监督已完成并复算](051-analysis.md)：与046同人口、同控制、step0逐值相同，固定λ0.1令位置/速度/航向MAE分别+1.637m/+0.00825/+0.02937°；输出和路由确有改变，但没有净增益。单源更准并不等于混合最有益，当前效用监督和ReLU份额可能存在任务失配；数学反例成立，真实占比/因果仍需小样本冻结诊断。保留046对照，不晋升051、不盲扫λ。050仍只有RUNNING回执，尚无正式规模TCM结果。
