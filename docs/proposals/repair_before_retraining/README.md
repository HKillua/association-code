## 成本估计与验证边界

参考按017旧速且完全不计微批加速估计：TCM约.54h、TAM5.10h、TFM10.30h、JOINT约3.45h、校准.48h、11次V约1.66h、终评与准备IO约.6—1.0h，总约22.1—22.5h。JOINT仅依据013两步外推，误差可能大，24h是封顶而非保证。

候选按018phase墙时拆分：共享约8149.64秒（2.264h），每臂按最慢旧适配/评价＋重复准备约907.25秒；加每项60秒规划余量后总约12078.65秒（3.355h）。新v2、共卡、IO可能改变实耗，不能以旧串行3.11h承诺完成。

本地306项CPU检查通过17.126秒；含dropout=.25的合成full与shared＋四独立臂模型/损失/Adam状态、采样、身份分数及物理输出逐值一致（计时除外）。代码与任务命令已独立复核，详见[验证记录](verification.json)。本地无真实Linux服务、CUDA或v2 MTAD训练结果；这些检查只证明软件行为。服务语义与现场责任见[执行约定](../../server_autonomy.md)。
