## 034属于什么

**034是我们自己的候选物理teacher，不是TMTAFF baseline。** 它延续032的`support_residual_v2`、`scaled_log`速度、位置底座、self/cross物理监督与身份BCE，唯一设计变化是把航向绝对预测改成“可见观测的圆周插值/端点保持＋网络角度修正”，并将航向输出行置零初始化。观测底座只读取当前anchor的可见航向，不读取reference。

033是原适配baseline的TCM4000；035冻结033再训练TAM关联。037是在该参考路线检验圆周输入表示的修正版，也不冒称作者原版。034的物理误差不能与033的latent MSE直接排名，034也没有评价关联或融合收益。

## 直接去掉学习部分的时间变化，结果几乎不动

对每个片段，使用全部Q64预测构造平均位置残差、平均log速度和航向残差的圆周均值，再加回原来的时变底座。**均值构造不使用目标或目标mask**；评价仍保留全部原有效目标。这是已有输出的事后诊断，不是重新训练的替代模型或在线算法。

| 指标 | 原034 | 学习部分固定为每片段均值 |
| --- | ---: | ---: |
| 航向MAE（度） | 56.629270 | 56.629258 |
| 位置MAE（米） | 8924.182483 | 8924.179666 |
| 速度MAE | 19.727328 | 19.727376 |
| log速度MSE | .705085456 | .705089271 |

相对于近似底座的航向残差，片段内时间标准差中位只有0.000365°、最大0.001695°；各片段平均修正的总体均值为−4.364°，1619/1635条为负。模型输出航向本身的时间标准差中位有47.62°，但主要来自观测底座，不能当作网络学出了转向。

位置残差时间标准差中位0.796米，而目标相对于底座所需修正的时间标准差中位约5446米（局部切平面近似，仅作量级诊断）；log速度为.000110，对目标.595660。结合上表，当前输出近似“时变观测底座＋每轨一个固定修正”，学习到的时间变化几乎没有效果。

**数值边界：** 本地没有034真实权重及normalizer均值，无法逐位还原归一化/反归一化往返。直接float64原量测控制的整体航向MAE为55.935519°，FP32近似底座为55.936058°。一个半周边界点`4618:9002:3`在两种计算下会选择不同圆弧，差42.525°；若忽略它，会制造假的残差动态异常。因此本报告使用与实现一致的FP32时间/半周容差近似，仍不称bit-identical。上表微小差异用于说明“几乎不变”，不宣称万分之一度级真实收益。
