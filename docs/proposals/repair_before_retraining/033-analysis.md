服务器S2L原件保留，但其“训练量不足假设未获支持”的推断不采纳。1000步窗口均值为.101538→.0150653→.0150387→.0125604；近似持平的是1001—2000与2001—3000两个窗口。对应中位数为.0149714→.00936424→.00889457→.00821500，仍在下降。不同训练批次的loss均值不能代替相同V人口评价，更不能推翻上表已观察到的改善。
