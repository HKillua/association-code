**确定事实：验证距离总体大幅缩小，400步后继续缩小，而后半程排序和F1没有持续变好。** 正/负距离中位数从TAM100的.329876/1.423033缩至TAM1000的.0000148298/.0000159173。选中600仍有28983个不同分数、没有精确零分，不能称全部输出相同；AUC也说明存在判别信号。不过所接受的负对仍多于正对四倍。

以600原缓存和实际margin复算、让正负类各占一半，验证CL为1416.066，而501—600步训练均loss为19.014；验证中所有负对都处于margin内。**这两者不是同一批数据**，还同时涉及训练dropout开启/验证关闭，不能据此直接认定dropout或loss代码错误。它提供了比盲目加步数更具体的待辨别假说：训练模式下的距离是否主要由随机扰动维持，确定性表示是否过度收缩。梯度裁剪频繁也是记录事实，不单独证明优化失败。

一个解析尺度参照：若正负两类都输出同一固定距离`d`，平衡CL为`.25[d+relu(m−d)²]`；当`m>.5`时，这种无判别等距解在`d=m−.5`达到最小值`m/4−1/16=18.752835`，与后100步均loss18.972534接近。它说明“loss约19”本身不足以证明学会身份，不证明实际两类等距，更不单独证明dropout根因。

长间隔确有更差表现：原阈值下>1800秒非重叠对AUC=.659923、P=.142579/R=.606354；但**支撑区间重叠**的13108对仍有4741条FP，P=.144687/R=.839791。按时间分层只是描述，其正例率及场景分布不同，不能据此归因或临时删除难例。
