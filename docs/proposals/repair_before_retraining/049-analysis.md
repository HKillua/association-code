|--:|--:|--:|:--|

300步所有22,912个多片段输出点的速度为23.125±1.53e−6、航向为4.93855±1.14e−6。预测不是只“太平滑”，而是几乎不响应任何场景、目标或时刻。358条轨迹输出内的位置跨度中位数为0；其真值跨度中位数为纬度.1051°、经度.1586°。有效真值点的纬/经std分别.3986°/.5647°，远非任务本身恒定。

### 代码与原文交叉检查：没有找到能直接归因的索引或mask错误

已比对实际执行树`d2ce3f7`，当前四份核心文件与运行时相同；直接读TMTAFF本地PDF第7—8、12—15页及Figure6。正对端点重排与真值顺序一致，TCM冻结并置eval，微批按完整batch的逐属性有效计数累计，uncertainty正则只加一次。训练与评价均由BOS自回归，没有teacher forcing到自由推理的额外切换；评价后下一更新也重新启用fusion.train。相关实现见[训练装配](../../../association/training/fusion.py)、[TFM结构/损失](../../../association/models/fusion.py)。这些检查不等于所有实现问题已排除。

三个更具体的待验证线索：

- **目标时刻没有直接送入TFM decoder。** decoder只收到零初始化BOS、自身latent历史和FC memory，没有query time、step PE或对应物理观测锚点。自回归仍可能学出时序，不能据此声称理论上无法输出动态；但本轮需要先验证输入条件在哪一层丢失，而非继续加深。
- **当前时间适配增加了混叠风险。** [输入表示](../../../association/models/timed.py)为`ReLU(W(normalized_state + PE4(tau)))`，原文Eq3同样先加PE，但原文是固定序号pos；我们改成随场景物理跨度变化的tau，TFM没有独立tau用于区分。单位PE振幅相当于训练位置std约55/61km。代数上取`state₂ = state₁ + PE(t₁) − PE(t₂)`，两组不同状态/时间可得到相同embedding；tiny计算最大差约5.96e−8。它证明表示有歧义，**不是已经证明本数据碰撞或63.8km错误来自PE**。投影W由原文可训练变成当前冻结也是已披露适配。
- **属性尺度与递归须分别检查。** 航向直接输出degree，圆周loss对每degree的导数上界π/180；uncertainty权重不自动保证共享参数梯度平衡。后续应测实际分项梯度，不能只看标量loss。推理递归反馈FC memory，而训练输入来自TCM，这与原文p13/Algorithm1的真配对训练、递归推理叙述一致，不能直接叫实现bug；恰两片段也坍塌已说明它不是唯一解释。

下一项最有价值的是对**已有0/100/300权重和同一小组输入**做层级输入敏感性检查，分别看TCM输出、左右encoder、FC memory、decoder输出的跨输入/跨时刻方差及配对替换响应；记录首对与递归各步，先定位“哪一段开始变常量”。配合少量固定训练正对的分项反向、只测梯度不更新，记录log_variance以及四属性对共享decoder/head的梯度；小样本只用于定位，不能当新V主成绩。这属于新forward/反向任务，本次没有执行或扩大预算。若memory有信息而decoder丢失，优先研究显式时刻条件或物理锚点残差的单因素修订；若FC前已经常量，先查更早层；若TCM输入已近常量则回到补全。不要直接把051候选融合的负结果和049混成同一个失败：两者架构、监督和估计人口不同。

本轮不改049权重、数据、训练配置或固定300端点，也不把100更好的整体MAE临时改作正式结果。049不通过物理融合效果验收；当前还不能声称baseline完整复现或我们已超过论文。
