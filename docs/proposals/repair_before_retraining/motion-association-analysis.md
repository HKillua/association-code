# 运动恢复是否改善关联：完整V零训练比较

2026-10-20，用户批准后本地CPU完成。**普通运动控制确实改善了关联：保持、首尾运动、多点OLS的场景macro-F1分别为0.61563、0.72102、0.72717。** 共用保持阈值时两种运动仍明显改善；因此收益不只是重新选阈值。OLS相对首尾运动的额外收益较小，且依赖工作点，不能宣称全面更优。

## 比较口径与证据边界

复用[R2原生预测](native-motion-analysis.md)，不重新训练或拟合参数。完整V64场、17个共享身份组件、1635轨、29008对，其中3297正对；全部`i<j`配对及所有Q64查询保留。每对统一计算64点球面距离的RMS，取负为分数，半径6371000米。来源、身份、支撑及位置真值均不参与评分；身份只生成评价标签。脚本不加载缓存中的`target`/`target_valid`。

主表各臂按同一既有程序在完整V选择场景macro-F1最优阈值，另报告共用保持阈值。所有分层沿用整体阈值，不重新调参。三臂都是全片段离线普通控制；V已反复暴露，场景有关联，不作独立测试、统计显著或学习创新成立的主张。

## 收益在哪里，仍错在哪里

| 同一整体自选阈值下的分层 | 配对数 / 正对数 | 保持F1 | 首尾F1 | OLS F1 |
| --- | ---: | ---: | ---: | ---: |
| 同源 ITSA | 14609 / 1534 | 0.577682 | 0.698726 | 0.703338 |
| 跨源 MSTSA | 14399 / 1763 | 0.645515 | 0.739638 | 0.747331 |
| 至少一个共同支撑Q点 | 12695 / 906 | 0.606921 | 0.710102 | 0.723764 |
| 没有共同支撑Q点 | 16313 / 2391 | 0.622485 | 0.730611 | 0.732831 |

“没有共同支撑Q点”只指Q64网格上没有同时位于两条原生支撑内的点，不等于连续时间区间完全不相交，也不据此删除pair。

- **仍有明确退化场景。** OLS自选阈值比保持50场好、14场差；共用保持阈值51好、13差。场景211从1.000降至0.471，共用保持阈值也仅0.667；4652从0.814降至0.500。没有按这些反例添加回退规则。
- **位置改善不保证逐场关联改善。** 将既有R2逐场位置MAE与本次F1事后对照：39场两者都好、11场位置好而关联差、11场位置差而关联好、3场都差。211是两者都退化；4652位置MAE反而改善1549米。该分解说明应直接评价关联，不能用位置误差代替。
- **不能把剩余错误全部归因于跨源偏移。** OLS的2427个FP中，同源1276个（52.58%）、跨源1151个；同源precision仍仅47.36%，跨源54.90%。匿名校准需要直接验证额外收益，同时保留运动一致性和时间支撑问题。
- **漏关联集中于缺少共同Q支撑的配对。** 这组有全部正对的72.52%，贡献OLS漏报的84.63%（633/748），召回73.53%；有共同Q支撑组召回87.31%，但precision仅39.83%。两类困难不同，不能靠删去某组提高结果。
- **误报有场景集中性。** 1396、1977、1457、1391、944五场留下534、321、297、254、120个FP，合计占62.88%。场景大小和难度混合，不能仅凭该集中性确诊原因。

## 对后续方案的影响

DE：原生运动带来的物理收益能传递到关联；两种运动控制都明显强于保持。当前035适配TAM的0.5129和021 teacher的0.6303也低于这次普通运动控制，但预算、表示和选模不同，仍不能据此称完整系统超过TMTAFF。

AI：后续关联应保留明确运动/位置证据，再检验匿名共同偏差估计有没有额外价值；仅让网络替代几何、只加训练步数或单独调整阈值，缺少当前证据支持。补全学习修正须对照普通运动，并同时看关联变化。UN：匿名校准是否有效、哪些同源误配来自长时外推、融合是否因此改善，仍未被本次检验。

下一步仍是R3无校准／一次匿名校准／有限迭代的具体比较方案，以及R4固定分组的普通融合。OLS是强对照，首尾运动保留；不根据V反例挑规则。baseline的042模式诊断独立等待服务器回执。本次不新增训练、服务器READY或开放T_test。

## 执行、复核与复现

实际一次运行退出0，约0.74秒。代码：[CLI](../../../tools/analysis/motion_association_control.py)；[2项聚焦测试](../../../tests/evaluation/test_motion_association_control.py)覆盖球面RMS、平分AUC、完整候选/空场、身份不改变分数及真值数组不可读。独立实现用单位球向量cross/dot替代haversine、独立阈值扫描复算：各臂分数最大差低于3×10⁻⁹米，整体/来源/逐场计数、AUC和纠错数一致。

历史位置关联控制的256组节点/来源/pair/标签及64组秒数网格逐值一致；hold分数最大差5.81×10⁻⁹米，指标完全复现。本次关联保持本来就是FP64，不沿用旧FP32补全底座的0.22米MAE差异。
