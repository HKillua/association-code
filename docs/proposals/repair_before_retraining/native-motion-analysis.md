## 反例反映什么

- **远期静止保持确有主要代价。** 无学习的原生运动已带来大幅收益，继续只加decoder深度/训练量不是当前优先项。此前70轨Q不足的拟合漏洞也已去除。
- **运动不能解决来源坐标偏差。** 9001全体MAE7963.42→3282.60m，9002为9926.33→6505.69m；支撑内两源仍约0.35m和4356.97m。来源校准需要跨轨参照，不能要求单轨运动凭空估出绝对偏移；9001/reference复用仍限制降噪解释。
- **全片段线性趋势有真实失败。** 场景211为4440.61→8712.61m，2715为3835.25→6835.77m；14个退化场和475条退化轨保留。它们支持检验运动修正/支撑可靠性，但不证明某个学习门控一定有效。
- **更强普通控制抬高候选门槛。** 下一补全候选须对照native运动，验证额外学习价值；不能再只胜静止保持就称创新成立，也不能据这次控制宣称已超过TMTAFF完整系统。
