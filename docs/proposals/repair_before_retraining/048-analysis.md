## 逐helper证据：先检验效用识别，不先放大权重

从64个NPZ重算全部路由计数与汇总，与报告一致；权重严格等于`relu(u)/(1+sum relu(u))`，anchor为`1/(1+sum relu(u))`。下表是045新组，helper“有益”指单独采用时比anchor更准，真值仅在预测固定后用于诊断。

| 统计 | 位置 | 速度 | 航向 |
| --- | ---: | ---: | ---: |
| 有益helper被赋零权重 | 36.29% | 29.42% | 47.86% |
| 无益helper被赋正权重 | 25.11% | 26.90% | 26.31% |
| 存在有益helper却全部被拒的anchor-query | 13.28% | 15.96% | 14.86% |
| helper总权重分给无益helper的比例 | 25.66% | 24.23% | 26.85% |

这不是完全没有识别能力：被接纳helper中有益比例为63.38%/69.07%/62.90%，高于候选原比例40.55%/45.99%/46.10%。但符号可靠性明显不足，单纯放大正效用不能救回已归零的好helper，还会放大已接纳的坏候选。“单独不更好”也不意味着任意混合必然有害，不能将上述权重比例直接等同污染损失。排序与符号标定尚未完全分开，048亦无固定同成员/同权重只换角度聚合的对照，不能确诊航向聚合为主因。

下一最小监督候选是保留特征、网络、原回归/物理目标、训练构造与权重映射，只增加原训练效用`y>0`的符号辅助监督：`L_new=L_old+lambda*BCEWithLogits(u,1[y>0])`。lambda须事前固定，沿用现有监督mask与归一化，不在V挑阈值/权重。它可能增强符号判断，也会改变u幅度和实际融合份额；近零y会被完整二分类推动，因此不能预称解决噪声、概率标定或单独验证排序。仍用同人口物理误差及原保护条件验收，符号率提高但物理效果变差仍不通过。**本页仅提出待具体化的单因素，不实现、不新增READY。**
