# 补全继续排查：锚点和局部趋势消融

2026-10-20，用户要求逐模块保证并推进实验后，本地CPU完成一次完整V零训练诊断。**两种简单修改都未改善整体补全：拟合锚点使位置MAE增加1.17%，固定局部半窗增加21.09%，不替换现有控制。** 补全仍未通过效果验收；结果缩小了可直接采用的改法，没有证明所有学习修正或局部运动都无效。

## 固定比较

复用R2的64场、1635轨、46051个native点、Q64共104640查询，其中81207有位置真值、54305在自身支撑外；全部29008关联候选/3297正对保留。沿用原manifest、cap128、真实秒数、逐属性mask，不读T_test、不训练、不选窗。输出、关联分数算完才读取身份及缓存reference目标。

| 臂 | 唯一修改 | 要回答的问题 |
| --- | --- | --- |
| native OLS | 原全片段OLS斜率＋真实端点 | 固定对照 |
| 拟合锚点 | 全局斜率不变，从同一拟合线的端点位置延伸 | 真实端点与拟合趋势的偏离是否拖累外推？ |
| 局部半窗 | 真实端点不变，前/后分别按首/末K点拟合斜率 | 全片段平均运动是否不适合端部外推？ |

K在开跑前固定为`min(N,max(3,ceil(N/2)))`，至少3点（只有2点时保留2点），不搜索参数。两点轨三臂相同；三点轨局部与全局相同。三臂支撑内原生插值逐值相同，未裁纬度或删除短轨；8条零Q支撑、62条单Q支撑轨全部保留。

## 解释与决定

- **DE：** 当前真实端点＋全局趋势对照优于这两个整体替换；均值、尾部、来源和完整关联结果一致支持不采纳局部半窗。
- **AI：** 短窗口斜率估计不稳、局部运动不代表长时外推，均可能造成局部半窗失效；不能直接确诊为量测噪声，也不能由固定半窗的负结果否定所有局部模型。
- **UN：** 哪些可见条件能可靠识别修正需求，以及受约束的学习残差是否有增量，仍未验证。拟合锚点不消除每条轨的共同来源偏移，不能当成跨源校准。
- **决定：** 保留原生真实端点和全局OLS/首尾运动作为普通对照，不继续凭V搜索局部窗口或整体更换截距。补全下一学习方案围绕保留可靠观测、稳定运动基础上的受约束修正形成具体对照；本次不授权/启动该训练。速度、航向和学习补全仍未验收。

关联的支撑可靠性与匿名校准、融合的固定分组普通对照仍可并行准备，不能以其进展将补全结案。042为独立baseline模式诊断，最新fetch未见服务器回执。
