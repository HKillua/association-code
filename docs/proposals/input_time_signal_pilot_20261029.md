## 1. 起点、撤回与创新筛选

**撤回**“110证明056的mean_diff置零使F1下降0.785”。110是容量诊断，108无模型前向；真实056为22维强几何/运动/支撑摘要，没有该字段。22维是否已经足够、原生事件动态是否改善状态，均为待检验问题。122只有Q64组平均一阶相对残差负结果，不能给全部时序方案下结论；EIV、插值、错误关联、局部模型失配仍是竞争解释。

- **输入单元**选IT-C4，主模式为系统接口审查：从实际汇总算子能丢掉什么信息，走到真实身份任务里这些信息是否可学。新增价值候选是可测的时间形状适配，不是先定等变网络；截断谱系数也不冒充无损原生表示。
- **时序单元**选IT-C5，主模式为成熟状态估计适配：同原生观测和输出人口下，区分直接插值与允许修正观测的动态估计。新增价值候选是对断轨/异步带误差航迹的可归因改善；不把Kalman、RTS或GP本身说成原创，不因其有先例否决验证。
- 近邻范围继承完整AP的GPTR/TSP时间错位、SemiDANSE、Time-IMM及EQ-Reg，未穷尽海上所有同类工作，不称首次。已有同机制经验用于限定条件、选择强控；若简单控制已经有效，可保留其实际价值，再判断更复杂方法是否必要。

## 2. 输入单元：强22维之外是否有可学时间形状

### 2.1 问题、干预和竞争解释

在同canonical_all/Q64、相同全部i<j候选和原标签上，检验距离随时间的低频形状是否超出22维强摘要。真实22维还含native OLS/端点速度，不能称完全无时序；原108的literal碰撞不作为本项主证据。

对每pair定义`z_q=log1p(Haversine(p_i(q),p_j(q))/1000)`，Q=64。新形状为去均值z的前8个非DC正交DCT-II系数：

`c_k=sqrt(2/64) Σ_(q=0)^63 (z_q−mean(z)) cos[π(q+1/2)k/64]`，k=1…8。

该表示保持pair交换对称，保留部分早晚与平滑变化，未保留全部方向/细节，也不是native事件编码器。三个竞争解释必须一并检验：有序信息；额外无序分布统计；额外输入/训练容量。若当前Q64已删掉有用原生变化，本项也可能无增量；因此负结果不淘汰原生时间输入整个家族。

### 2.2 固定四臂与训练范围（实现后方可发布）

| 臂 | MLP前30维输入 | 判别用途 |
|---|---|---|
| A0 SUMMARY | 原22维＋8个恒0列 | 真实强摘要的同新训练预算控制；不能只拿旧056不同预算比较 |
| A1 ORDERED | 原22维＋c1…c8 | 追加有序低频形状；A1−A0只是适配总增量 |
| A2 DISTRIBUTION | 原22维＋z的q=.1,.2,…,.8八个分位数 | 同维额外无序信息强控，不能只与零列比就宣时间顺序机制 |
| A3 SHUFFLED | 原22维＋逐pair固定随机置乱z后的前8个DCT系数 | 破坏新通道的物理次序、保留该pair的z多重集合；不重排原22维、不改物理状态/标签 |

置乱在特征构建时，以固定seed20和完整名单中的split/scene序号、pair序号确定独立子流，不能按标签、误差或V效果择置乱；相同pair每次取回同一排列。**全数据共用一个可逆置换不是有效阴性控制**，因为学习器可能重学该坐标顺序。单次逐pair置乱同样不是置换检验零分布；其压缩后的尺度/信息量也未完全等同A1，结果只作机制线索，不给严格因果定理。

- T2100与完整V300沿当前manifest，T_test封存；全部原候选、同源正对/无共同支撑/短轨完整保留。每臂normalizer只在T拟合，同一22列必须相同；0列std按既有规则记1。原22列构建及FP32缓存/FP64base不改。

- 每臂仅固定末步在全V一次打分，按既有完整场景macro-F1阈值选择规则开发阈值；所有阈值、scores、raw指标和全人口保存。V选择阈值与多次既有开发明确披露，不能称独立确认。旧056分数另列参考，不归本轮新增方法收益。
- 主估计量为A1对A0、A2、A3的完整场景macro-F1差；同时列P/R/FP/FN/AUC、ITSA/MSTSA论文指标，按同源/异源、共同支撑有无、组件/去最大组件分层。初轮只验证raw身份信号；不能把raw改善叫完整融合增量。解码若另做，四臂须同一固定规则并独立报告，不拼不同臂冠军。

### 2.3 判据与出口

A1相对三强控均有方向一致且不被最大组件独占的增量→支持进一步发展保时间形状表征；仍需native时刻、方向信息和可信近邻共同协议。A1只胜A0而不胜A2→更多分布信息足以解释，不支持时间顺序主张。A1和A3相近→该探针未给稳定顺序证据。四臂无有意义差异或尾部/子组反向→结束这一个8系数配方，保留完整结果；不加频率、换seed、调参或改采样来自动续跑。原生高频、时间间隔及方向尚未测，不能写为所有输入创新无效。

**当前缺口**：本文件未实现30维抽取/四臂复用runner，未实查服务器缓存能否重建全部node级原22维证据，未确定各真实文件路径与launcher命令。当前仅`design-ready/partial`，须完成本次会改变的接口/批次绑定核验和实际路径后，才由主仓单独发布任务；不以新模拟训练链作前置，不让旧runner默认偷偷加V中期选步。

## 3. 时序单元：原生位置的透明CV滤波/平滑控制

### 3.1 可建立条件与不作的推断

| 条件 | 当前状态 | 合法建立/测量 |
|---|---|---|
| uncapped原生事件/秒/逐属性valid/谱系 | 代码接口已存在，实际产物可用性未现场核 | `retain_native_events=True`；若旧NPZ未保存，则从当前Level1量测显式读取，不把Q64反插值成native观测，不读封存测试 |
| 状态和观测 | 可建立的工作模型 | 每fragment独立位置/速度状态，观测仅原生lat/lon；不把source编号、身份、ref或Q64补值当观测 |
| 动态/观测误差独立、Gaussian/零均值 | UN，不作为既证前提 | 将参数称工作平滑尺度；不向融合输出已校准协方差，不用该协方差认证覆盖；保留已有滤波相关性/真实偏差竞争解释 |
| 初始化/全部query输出 | 可明确的离线合同 | 首原生位置及零速度工作prior；前向/平滑查询规则见下文，固定WS组/首代表/FULLQ64及原raw支撑不动 |
| 尺度与选择 | 可在T建立，当前尚未拟合 | 预定小网格、仅T32参考选择一个通用尺度再冻结到V；这是有监督开发，不能称无标签绝对精度识别 |

复用GPTR已核的真实Δt转移/噪声积分原则，取最简单平面CV工作模型，而非直接移植其SE3/WNOJ或闭式Jacobian。SemiDANSE说明H/Cw必须明确，不能把“滤波”名称代替观测模型。没有已核海上同接口跨域C复现，本阶段如实标缺，不无限检索才允许透明验证。

### 3.2 状态、原生观测与查询规格

每fragment用其首点为原点、平均可见纬度作固定north/east chart，纬差及累积展开经差转米；该chart用完整窗口，故是离线权限。`x=[pN,pE,vN,vE]`，

`F(dt)=[[I,dt I],[0,I]]`，`Q(dt)=q [[dt³/3 I,dt²/2 I],[dt²/2 I,dt I]]`，`H=[I,0]`，`R=I m²`。

R=I是固定工作尺度，不是测得1m噪声。只选择`rho=q/r`，单位s⁻³；候选`10^k, k=-10…-2`共9个，候选外不扩搜。首点作为位置prior均值，P0=`diag(1,1,1/3600,1/3600)`（分别位置m²、速度m²/s²），速度0；首观测已经用于prior，不再重复更新。之后按真实原生秒作标准Kalman prediction、innovation和Joseph covariance更新，RTS用相同前向量/参数反向平滑。逆运算用解方程；非有限、非正定失败保全，不自动jitter、更换配方或删轨。

原生观测时刻和Q64 query合并为排序timeline，同刻先观测后query；query只有空观测，不新增测量。RTS在完整timeline平滑，输出全部Q64；query在首/末观测之外分别沿平滑端点位置/速度作CV外推，不把外推称有真实支撑。纬/经还原遵守短弧和合法范围；任何无法还原的真实轨迹保留为失败，不能静默切换回旧OLS。

前向均值可以作为额外内部控制，但**不与RTS当作同未来权限的纯算子消融**：首观测前query使用首点prior（前视），不能宣严格因果；已有WS本来也用完整离线场景。若以后研究严格在线，应在首事件未到时保留“尚无输出”及完整漏报人口，并另立前缀关联/到达时间/初始化合同，本项不伪造在线资格。

### 3.3 拟合、六臂与评价终点

1. T侧固定当前manifest中前32个T_core场景，不依效果选场；只用位置监督，按既有reference offset/gap600/valid规则将同一场景Q64位置对应到每个fragment身份。每candidate按“场景等权→有有效参考的fragment等权→有效query MAE”选最小一个rho，完全相同人口；并列取更小rho。各候选、无参考fragment/点、成本完整保留。该监督不进入V动作，也不估源间噪声比；不用reference速度反推物理单位。
2. V侧固定原118的32场/9组件，原114 WS组/首代表、Q64、输出valid与速度/航向完全固定。每fragment独立生成OLD_OLS、NATIVE_CV_FORWARD、NATIVE_CV_RTS位置，分别接同Mean或同LOW支持贡献，得6臂；LOW沿121同冻结source顺序，只有贡献规则变化的比较才归LOW。两新状态模型均不加共享校正/收缩/学权重/τ。
3. 6臂使用相同原始support和回退规则，不能用滤波后方差删点或增加support。无支持时复制相应状态模型首anchor；全组/重复/漏目标完整保留。原Frozen FixedLOW另列历史强控，**不把旧中心应用到新状态后又归为单一动态收益**；如需组合，是后继独立factorial。
4. 主比较RTS_MEAN−OLD_MEAN与RTS_LOW−OLD_LOW的共同完整位置MAE/RMSE，分别归因并列；同时列6臂所有15配对、P95/P99、全部人口/coverage/重复、raw支撑内外、exact-native查询、时间距端点、场景/组件/去最大组件和全链成本。FWD对RTS只是未来信息/平滑差异，不宣纯模型优胜。
5. 一次T32×9工作尺度选择及V32×6完整评价，0神经训练/0GPU；CPU4/RSS4GiB/AS8GiB/7200s advisory。实际原生事件数、Kalman更新/RTS步数、原始读取、参考查询、评价与写盘都计成本，不把0训练说成0拟合。单次attempt；固定终点结束，失败不自动重试/改网格/删难轨/扩量。

### 3.4 否证、解释与当前缺口

若RTS在Mean/LOW两种贡献下均有稳定净增量且支撑内也好→支持在当前离线工作模型下发展状态—观测分离；不能据此证明原插值为根因或原生噪声独立。只在某贡献/支撑层好→保留交互和边界。RTS不胜OLD、机动/尾部损失或T侧选择不能转移→结束该CV先验/尺度配方，记录动力学失配等候选，不直接否定连续时间/学习状态模型。FWD更差可由未来权限解释，不能算在线方法天然弱。

**当前缺口**：尚未实现/数值核验不规则事件与query合并、RTS端点外推、真实chart边界、T侧reference对齐和6臂artifact绑定；实际原生文件/原32名单及命令需现场确认。当前为`design-ready/partial`，不是可立即执行任务。先完成具体实现和这些可能改变结论的核验，再单独发布；无需证明所有真实噪声条件才能作经验试验，但必须保留工作模型命名与失败条件。
