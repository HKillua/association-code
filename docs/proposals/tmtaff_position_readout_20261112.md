**对象与变量。** 固定原 T8 的16真对、1024 pair×Q、三个快照、参考、掩码和 CAP128 Mean。逐原微批复现 C93 原输出。逐查询读出使用同 Q 的 TCM 双输入、双编码器出口、FC1 前激活与后激活全局向量、FC2 后记忆、decoder 生成历史末 token、记忆与末 token 合并，以及当前解码输出 latent。FC1 两个向量本来就是全局，作为全局特征随查询给出。另读完整展平的编码器出口、FC1 输出、激活、FC2 后全部记忆、当前完整历史及两者合并；记忆中同下标 token 没有原生 Q 对齐保证，整段读出是接口敏感性。实际 FC1 输入逐元素核对双编码器展平，FC2 输出逐元素核对 decoder memory，完整历史逐元素复现 BOS 加自身先前生成 latent。FC2 列秩、条件数与反解误差另核，区分表示映射的可逆性和数据有限的读出误差。

**拟合与评价。** 每场两对共同留出。拟合标签及尺度仅来自其余不共享目标身份的场，任何训练/留出目标交集报错。每个探针用固定二次 Q 基线加归一化线性特征和 Q 的一次交互，惩罚 .01 为主、.0001 为固定灵敏度，保留全部设置；无调参选模、无神经优化或读取 V/test。绝对读出使用原训练坐标尺度，主评球面位置 MAE/P99、双支撑、分场、BOS/后续与预测对调时的误差。独立的无截距差向量线性读出仅用其他两异目标场，主评有向局地米差误差、方向一致和分离大小；同场同 Q 向量在相同地理尺度报告，CAP128 Mean、原模型、零向量和 query-only 为控制。99 个共同有效异目标 Q 是3场内重复，报告逐场和90个有向共同双支撑点（45个无向 Q），不进行点独立显著性推断。全段与同下标特征不可直接当成等输入量。

**判据与反例。** 可读性的证据要求固定主惩罚优于 query-only 绝对误差和零向量目标差对照，两个惩罚方向一致并至少两场目标差有益。平均位置、目标排序和尾部同时保留，CAP128 Mean 的实际物理误差作为独立尺度。强可读而原模型不分离支持后段利用不足，逐接口读出下降才支持所用线性族的可用性损失。阴性允许样本不足、非线性编码、全局／局部接口差别；不归因为唯一根因。反解结果不需要参考标签，不作为位置预测臂或新系统胜负。
