|诊断|控制和人口|主要输出|
|---|---|---|
|关联候选|每个片段首次到达是一个有向查询。候选来自已到片段和同刻其他片段。将最新观测留存上限 60/600 秒、距离门 250/1000/4000 m 完整交叉。比较保持末次位置与最新两点的恒速外推。同源和跨源分别统计。|存在同 A-B 候选、真候选入门、门内排序第一、真候选入门时仍排错、无真实机会的错误近邻、同刻机会与并列。全部片段保留分母。|

局部 CPU 执行各一次，0 训练，终点是三场处理完成和逐场、汇总 JSON 落盘。解析或语义冲突时停止并保留已形成记录。门与年龄组合用来诊断，不以最低训练误差作选模。关联若主要漏在门外，先检查时距和运动估计。若门内仍排错，比较允许拒配的约束指派并实测下一次真实观测的消歧价值。融合先看均值、尾部和观测年龄的共同变化，再决定是否继续检验递推滤波。三个训练场只支持开发选型，统计以场和目标为单位检查异质性，保留总体描述量。

### 追加的共时偏差诊断 v1

第一轮关联结果出现真候选与最近候选的明显分离。追加核对同三场的所有同刻双源观测。仅在事后按 A-B 找每源各一个的位置，保留歧义计数。同一目标内计算东、北米制位移的中位向量，按目标排序奇偶分成两组，两次互换估计组与检验组。估计组的跨目标中位位移用于检查另一组相对距离变化，并保留未校正对照。该步骤使用事后标签，检验的是共时相对偏差是否近似共享，属于机制诊断。局部 CPU、一次、三场、0 模型训练，以保存两折及各场计数为终点。
