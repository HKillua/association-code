## 问题、机制与反例

个体历史在 27/28 场降低随后报文位置 MAE，固定候选的关联错漏对秒仍多 94。邻轨在稀疏场再多 78，且 ID 换手减少。三类竞争解释分别是可达真边不足、同一个预测移动同时改变真假边的相对距离、实际决策的错秒由持续错链而非频繁改选贡献。预测降误差有可能确实改善真边排序，只是受空配或全局互斥影响，也可能整体平均被少数场扭转。先按已到证据和实际输出定位，才能选择后续关联对照。

## 冻结人口、方法和执行

仅重放 [原名单](../../online_observation/nemot_roster.json) 的 28 个已评 Level1 T_core 场，28 个共享 A 组件。该批本轮作为诊断人口，既有稀疏 24 场定义沿用。读取原 `history.pt` 与 `neighbors.pt` 及上轮匿名 `summary.json` 作一致性核账。KF、个体、邻轨同用上一轮的前缀配准、原始保持位置 4 km 门、60 秒新鲜、每端空配 `4000²/2`、原生事件指派与 ID 继承。观测钩子在全部臂决策之后记录，不改写预测、候选、权重、代价、指派或历史输出。只读取位置时间量测，全部场的无标签快照冻结后读 A-B。零训练，零选择，CPU 两线程一次执行；不打开其它划分或独立参考。评分接口只传 A-B 等同性。全量场保留，产物写新私有目录。HyperSSM 保留独立强对照，未进入本诊断。

## 观察量与解释

- 原生层的单位是每个当批更新键的查询。含首次、续报和该时刻对侧未过门新鲜键 ≤3 的子组。两端同刻更新时可各贡献一次，不能把查询数当成独立关联。保留无候选，并区分尚未见对侧真键、只见超龄真键、有新鲜真键但门内无真、有门内真。每臂真边未选时记录全部真边代价 ≥两端空配、或有严格低于空配的真边仍未选。后者按本地真最小成本胜、并列、败分开。这一观察不单独归因于求解器。唯一假边且真对侧从未见组单列接收和空配。
- 真／假候选残差由实际平方代价开根换算成米。每臂保留全候选和按查询最小真／假分布，固定上界 50、100、200、400、800、1200、2000、3000、4000、5000 m。主比较限定同查询真假边均可达，报告间隔 `最小假残差−最小真残差`、真严格胜／并列／败及三臂配对转移。看真残差变小的同时间隔是否缩小，记录实际伙伴、首报错/拒。边自身代价使用上一轮原更新时刻与缓存规则。原生查询与整秒可见的累计错漏是两个评价人口。
- 整秒层同原评分从 0 至末报向上取整。每条无序跨源键对的连续错误评分秒形成错配段或漏配段。段长由可观察的连续整秒计，固定 ≤5、6–60、>60 秒，分层报段数和对秒贡献、P50/P95/最大。末格仍出现为右删失。段结束时先区分两端共同新鲜支持是否消失，两端仍活跃的再记决策改变。漏配段的支持中断与已重新关联分开。逐秒配对拆共同／新增／去除错漏秒，新增与去除分别沿同一整秒连续性统计段长。逐场的 FP/FN、候选、报告、首报及关键持续 ID 指标与原件对账。按原场稀疏定义分层和逐一剔组件，另把稀疏按前缀配准成功/弃权描述性分开，保留全部反例。

## 终点

主要结果为有真有假查询的配对排序转移、漏配机会归类、错配与漏配段的累计量/持续分解。若只见整体单边变近而真假间隔或排序未改善，保留预测对照，把关联排序与可匹配性作为下一项独立问题。若真实错漏主要源于门外或未到，则对应评价候选时域和待定机制。对支持中断后消失的错链不记为成功修订。只描述此批数据，未知的原因保留为机制假设。终点为一次成功或技术失败保全、独核、Record→Squeeze→Mode C。无后验调参和补场。
