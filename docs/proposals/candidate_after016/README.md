## 唯一的模型表示改动

现有原生时间为`tau=(seconds-scene_origin)/20`。在手工特征进入小型MLP之前，用训练数据一次确定的常数S把其时间坐标变为`tau/S`，再做差和乘积：

`S = max(1, max(abs(valid native tau), abs(query tau)) over T_core packed FP32 inputs)`。

- 身份头的`first/last/span`先缩放，再计算成对绝对差和乘积；`log1p(count)`保持。
- 效用头与普通可学习门控的`query-first/last-query/span`使用同一S；计数项保持。`identity_with_utility`也遵守相同规则，但首轮fit仍不启用这个额外身份训练阶段。
- 不修改Transformer的20秒sin/cos编码、物理时间或支持判定；不裁剪长轨、不删样本、不改标签或真实轨迹，不用V/reference数值/测试集选S。
- S在训练装配后仅计算一次，作为非训练量写入检查点与run。验证/导出/恢复只读取同一S，不能每场景重算或以V更新。新配置显式启用，旧检查点缺此策略仍走原行为；不得将旧权重默认为缩放版。
- 模型规模、速度输出、物理loss、训练采样、门控公式保持现有值。本改动不会自动解决所有位置/速度误差；本轮用实际学习曲线判断这些误差是否随训练减少。

## 已完成的CPU证据

读取015保存的512个T_core场景契约、54792条轨的首尾和查询时间，无原ZIP重扫描。因原生时间单调且cap保留首尾，端点可精确给出有效时间最大绝对值；查询点另外纳入。复算得到S=360.0。这个值是当前训练契约的结果，不是永久硬编码常数。

固定seed20、零语义的合成小头输入，跨度tau350（不加载真实模型权重、不跑真实数据推理）：原身份logit9089.74、sigmoid=1；仅缩放手工时间后logit0.19990、sigmoid0.54981。效用输出范围由约[-47.20,40.98]变为[-0.0851,0.1133]。这证明所建议操作能去除这个合成反例中的数值放大，**不证明真实准确率提高或候选收敛**。证据与可复算命令见[time_scale_audit.json](time_scale_audit.json)、[脚本](time_scale_audit.py)。未改变生产模型、未新增GPU计算。
