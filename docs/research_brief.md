# 研究目标与当前判断

目标：**关联和融合各一项主要创新，补全一项辅助创新，最后证明完整系统收益。** 对应华科电信学院电子信息专硕研究；以具体问题、任务适配和有效比较支持增量贡献，不要求颠覆性突破。在线/离线形式仍开放，不预先锁定某一网络或“全局关联＋学习型平滑”。

研究采用可靠基础、拆解不足、迁移成熟机制、针对任务适配、对照验证的路线。三个贡献须有可区分的作用；同一校准造成的上下游收益不重复算两项创新。接受负结果，不以模块名称、代码量或文档量替代贡献证据。

## 每个环节分别验收

用户2026-10-20明确：允许并行推进，但补全、关联、融合每一步都必须得到验证。**当前关联已有单种子开发集学习增量，尚未完成贡献验收；043未建立补全整体学习增量，融合保护条件未通过。** 普通运动控制有效、代码检查通过或任务COMPLETED，均不等于候选模块已经做好。补全失效分析与针对性修订继续独立推进，不因关联/融合开工而搁置。

具体优先假设是**正负目标尺度配平**，不是把论文公式认定为抄错。以下写单例损失，批次仍取均值；m为训练前一次校准后固定的值。已读原文Eq.15与当前实现一致：`L = 0.5 * [y*d + (1-y)*relu(m-d)^2]`。建议下一项仅把负项乘固定`1/m`，得到`L* = 0.5 * [y*d + (1-y)*relu(m-d)^2/m]`；令`z=d/m`，它等于无量纲目标`0.5 * [y*z + (1-y)*relu(1-z)^2]`乘m，因此配平正负项而保留原正项导数尺度，不增加V调参系数。保留047的冻结033、无dropout、校准规则、初始化/采样、学习率和评价规则。单例正项对距离导数仍为0.5，负项导数范围变为[-1,0]，避免同时整体缩小所有梯度；这不等于只将原总loss除以m。它是明确披露的目标适配候选，不是论文原式，也尚未证明能改善表示。保留035/047原结果作参照；若未来验证没有改善同场排序，就不再用扩大距离或训练loss下降自证成功。**该独立选项和配置已实现并经CPU检查/独审，缺省仍为论文原式；未执行新TAM实验或加入READY。** 扩容后的baseline仍先保留原式。若在新协议检验此项，两臂必须同数据、同TCM，不能直接拿旧047当唯一对照。

建议的最小位置改法是**端点锚定的有界运动修正**：在局部东/北米制坐标写`p_hat(t)=p_OLS(t)+h(t)*delta_v_endpoint`，每条片段的前、后外推段分别共享一个修正向量，不能让它逐query自由变化。先只允许支撑外修正，支撑内`h=0`；支撑外`h=600*tanh((t-t_endpoint)/600)`秒，使用同侧真实端点。令`delta_v_endpoint=v_star*z/sqrt(1+||z||²)`，输出幅度有界，近端为m/s速度修正乘有符号时距，远端被抑制；`h`饱和后的实际速度修正为`h'(t)*delta_v_endpoint`，不把参数本身说成全程真实速度。`v_star`只从T_core可见位置/真实时间确定，实施前固定，不能用V选上限。对所有来源同样处理，暂不宣称解决支撑内噪声或来源偏差；这类偏差不能由单轨自身几何完全辨识。速度属性与航向头形式保留，但共享网络重训仍可能改变它们，须独立验收；不把位置导数直接当原生速度属性单位。

辨别贡献的关键是与**同容量、只加支撑门控的自由位移头**比较，外加OLS普通控制。若只门控已同样有效，就没有证据证明新增运动约束带来额外收益，不能包装成学到更好运动。首先把这一比较写清，再决定是否需在支撑内长缺口使用端点为零的桥接修正；不要一轮同时试外推、桥接、pre-norm和去BCE后按V挑最好。这是待具体化的研究方法，尚未实现或授权训练。

048进一步缩小融合修订范围：045新组中，有益helper被拒比例为位置36.29%、速度29.42%、航向47.86%，无益helper被接纳约25%—27%；首先检验效用符号识别，不直接放大helper份额。它不证明监督是唯一根因，也不等于已经分开排序与标定。建议只增加原训练效用`y>0`的符号辅助监督`lambda*BCEWithLogits(u,1[y>0])`，其他目标、网络、特征、训练构造和权重映射保持；lambda事前固定。近零y也受二分类推动，u幅度和融合份额可能随之变化，不能称概率标定或纯排序修复。仍按原物理与保护项验收，细节及限制见[048分析](proposals/repair_before_retraining/048-analysis.md)。本轮已实现独立`utility_sign_weight=0.1`选项，默认0保持原loss/梯度/RNG路径；配置、符号标签与mask测试及独审完成，尚无真实新训练。下一步先在046原512/64、原OLS分组上单因素1000步，固定最终端点；不同时改成045分组。若在新正式数据比较，两臂均重新训练。满足保护后再比较统一/逐属性效用，不同时改映射、污染训练和网络。
