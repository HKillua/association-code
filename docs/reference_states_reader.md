# 原始参考状态读取接口

`association.reference_states.read_reference_states(archive_path, manifest, split=..., scene_ids=[...])`
只读调用方明确列出的`T_core`、`T_head`或`V_select`场景；拒绝`T_test`及跨划分请求。
它读取原生`真实场景/场景-N.csv`，要求列为`MMSI,time,lat,lon,vel,cou`，按A–B格式检查身份，其他格式列为问题。

返回各场景的原始CSV顺序、行号、原字段字符串、数值时间与`[lat,lon,vel,cou]`四维状态。
非有限值、不可解析数字、错误身份、同身份同时间的相同重复/冲突/无法判定重复均列入`issues`，不丢行或自动修复；调用方必须明确处理问题才能形成监督。
ZIP安全路径及场景编号复用现有解析，CSV沿用UTF-8 BOM优先、GB18030回退。

本接口不读取量测/关联表，不移动时钟、不插值、不排序/去重、不归一化或映射航向；不确定有效监督采样、缺测/噪声生成，也不修改或生成模型观测输入。未接入训练或CLI。
只用合成ZIP验证，未读取原生数据。它是参考数据读取接口，**不是TFM或完整融合实现**；原生参考的来源、时钟及其与单源量测的关系仍需后续协议明确。
