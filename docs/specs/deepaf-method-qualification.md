# DeepAF 方法核验：有限本地诊断

## 问题与边界

用户要求先确保已正确实现DeepAF。当前P/V网络核心可以对应原文，但固定组适配的训练目标、初始化及原生行为仍缺证据；099A/B/C正式同行比较处于HOLD_METHOD_QUALIFICATION。本轮只做本地CPU资格诊断，不读取Level1、不打开T_test、不领取服务器GPU，也不更改098。

原文依据：[Cui等，DeepAF](https://doi.org/10.3390/aerospace12030194)，§3.1–3.3、§4.1；核心一致性审计见[审计报告](../reports/2026-10-25-deepaf-method-audit.md)。该诊断不宣称原论文整系统或表格复现。

## 执行前固定合同

- 复用现有两套P/V网络，完整6＋6层、d32／4head／FF64。独立Cartesian驱动按Eq9/10构造当前量测差分、prev-V虚拟候选和自身反馈；允许没有真实候选。没有复制一套不同的网络。
- 31个1s样点覆盖0–30s，给定已正确归属的前6个带50m噪声量测作为启动段；从其OLS估计初始P/V和5条历史。这里没有自动起始、动态关联门或轨迹终止，属于已起始单航迹核心验证。
- 后续25个扫描：检测率0.9，Poisson(8)杂波，杂波坐标在真实目标周围±500m均匀产生；全体可见候选参与模型，不用GT筛掉错误候选。GT仅用于模拟传感器、训练监督和事后指标，不进入模型反馈、选择或门控。
- CV、CA、CT各64条训练／32条独立held-out，合计192／96场。初始位置每轴±200km、速度100–250m/s、速度边界50–300m/s。CV采用每轴σ10的离散随机加速度；CA采用每轴N(10,10)恒加速度；CT按原文区间[-π/60,π/15]解释为rad/s。CV/CA速度投影后梯形积分、CT精确转弯积分。这些离散细节属于明确选择，不冒称作者未公开的代码。
- seed=20261025，训练数据seed、held-out seed+1、采样seed+2；不重抽好看的数据。
- 两臂同初始化、同实际batch顺序，每臂**256次更新**，batch8、Adam .001、clip1、CPU1、TBPTT1／microbatch64。`native_labels`：P相邻truth差／V仿真瞬时速度；`adapted_labels`：P相对上步预测的纠偏增量／V相邻位置差。两臂用于检验训练解释差异，不根据结果反推作者实际配置，也不自动选出099正式loss。
- 初始与固定final两个held-out端点；不早停、不扫lr、不追加更新／seed。报告各运动的二维位置MAE/RMSE、内部V二维RMSE、逐扫描误差、检测／杂波／空候选计数。
- 控制为同可见启动段的OLS-CV外推和全候选质心（无候选时用OLS-CV）；后者不需要GT关联。它们用于尺度与行为诊断，不是论文同行排名。

## 结果如何解释

有限值、输入不读GT、真实无量测递推、单位／反馈正确是实现条件；独立场景上的学习变化提供行为证据。只看训练loss下降或软件退出0不构成方法合格。若某些运动／控制下结果差，分别报告，不挑一个总分认证；256步没有收敛也不等于原方法无效。不得以这次合成诊断替代真实Level1适配质量检查或最终稳定同行优势。

原生完整DeepAF跟踪系统的gate／起始／终止仍未复现。即使本诊断正常，适用名称也应为“已实现并核验DeepAF P/V核心的fixed056位置任务适配”。真实Level1资格证据和新实施冻结通过前，099继续HOLD。

## 追加一次1024更新核验（2026-10-25）

导入后独审未发现新的确定生产错误，但已有256更新没有保存权重，无法用旧权重区分一步映射与递推累积。只追加**一次本机CPU adapted_labels 1024更新**，不再重跑native_labels、不扫学习率/标签/结构。保持前述192训练/96合成验证、seed20261025、batch8、Adam .001、clip1、TBPTT1、CPU1；保存0/256/1024模型与Adam、实际采样记录。对原256记录只核初始化/实际样本/指标差异，不承诺跨机器Torch训练逐位相同。

三个固定端点都评价同一held-out；1024是唯一新终点，不根据V选择中间模型。控制和全人口不变，保存逐扫描及CV/CA/CT误差。无Level1原ZIP读取、服务器GPU、封存测试或正式099预算消耗。历史两臂512更新约276秒，1024纯训粗估约9分钟，评价/写盘另计；一次不自动重试，不因结果差追加步数。

额外输出明确标注**含真值的oracle影子诊断**：保留真实闭环该步的V、P/V历史与可见量测，只将当前前驱位置换为真实前驱，再独立计算一次预测；影子预测不反馈。首步无同等前驱纠正，单列不与后续混淆。不重置全部历史、V或重新训练。闭环对影子的差异说明前驱位置偏差敏感性，不能证明TBPTT1是唯一根因；影子误差不是可部署同行分数。

预定出口：若增加训练明显改善但仍漂移，按一步/闭环与时间曲线限定原因，不自动放行真实大训练；若未改善，停止扩展该合成配方并报告资格阻塞，不称DeepAF方法类别无效。若与简单控制接近且行为合理，也须核生产单条历史/q0/真实dt和球面适配。真实任务中P损失隐含位置误差的1/dt²权重，下一步须显式考虑，不能直接静默改loss。
