# 实际输入支撑分层（2026-10-19）

用户要求把当前问题落到代码。已批准的v2恢复修正已实现；本次补齐普通完整评价中的失效定位，不改变模型、时间窗口、训练分布、阈值、选模、原有指标或GPU预算。

## 行为

- 完整baseline及候选的predicted/oracle物理评价，复用已经算出的输出，额外按该组实际输入片段报告物理误差与覆盖。单源/简单融合仍保留原完整指标，不把其输入规则套成神经网络输入。
- 原生输入使用cap后的真实秒时间和可见mask；支撑为可见首末闭区间，区间内不保证每个查询点有实测。注册网格输入使用真实可见格点mask。零可见点不提供支撑。距离取最近实际可见输入点，而非编码单位、预测点或reference时间。
- baseline singleton也曾把原生输入送入关联编码器，但其物理输出仍按原规则只保已有观测；输入支撑不代表执行了物理补全或每个输入实际贡献。`prediction_valid`与缺失预测分母不变。
- 组内第一个片段是既有anchor。四类互斥且覆盖全人口：anchor支撑；anchor无支撑但该组其他实际输入有支撑；组内均无支撑；目标没有匹配输出组。预测错组不以真实身份修复；oracle单独报告。已有observed/missing仍用原真实身份并集，保持历史口径。
- 距离分层为≤300秒、(300,600]、(600,1800]、>1800秒以及没有可用输入；仅解释误差，不屏蔽训练/评价点、不裁远点。各层沿用原逐属性reference/prediction有效mask，零交集误差null，重复输出和未匹配目标继续保留。
- 附加统计不触发模型调用/重新关联/选阈值。普通完整评价自动写入per-scene和汇总；可选预测导出保存同一分层编码及距离，方便离线复算，无须为此重跑017/018。
- `evaluate_full_scene`的输入支撑参数可选，未传时保留旧输出；旧产物继续可读。新字段不能改变原三个区域的数值。CPU计算不受模型device影响，CUDA真实执行仍只在获批服务器作业发生。

## 验收

| 条件 | 可观察检查 |
| --- | --- |
| 不使用oracle修复预测输入 | 同身份片段在另一组时不能提供helper；错误身份实际同组时按实际输入统计 |
| 真正可见输入与时间 | 掩码隐藏点和NaN padding不进入支撑；非20秒间隔及最近点距离有手算例 |
| 不丢人口 | 未匹配目标、重复输出、零输入场景和无真值点保持覆盖分母；分层点数可加回全人口 |
| 不改主结果 | 开启/关闭可选诊断时原完整指标逐值相同；全场景汇总按误差分子/计数汇总 |
| 接入正式流程 | baseline/候选CPU完整评价与合成CLI输出含新字段，预测导出重载可复算 |

不新增训练/数据重扫、成本探测或通用验收框架，不把诊断实现称为模型效果已经改善。

## 本地验证

新增11项针对性CPU测试通过，覆盖上述几何、错组、全人口、逐属性有效性、汇总、两个完整评价入口、预测导出重载及损坏可选数组。全仓491项CPU测试通过（21.919秒、退出0），原生审计15项通过（0.045秒、退出0）；包含候选v2合成原生ZIP四臂CLI和baseline完整CLI。没有运行真实MTAD训练/评价或CUDA；017活动checkout、配置和历史产物未改。

对既有v2恢复修正另做有界复核：47项已有针对测试通过；独立非单位尺度例中可见位置底座误差为0，物理速度std放大1000倍后v2输出逐值不变。确认修正接入正式CLI，不代表真实误差已改善。

两路独立复核通过。代码审查另外以120个随机小场景核对：新旧所有原报告字段及artifact数组逐值一致，支撑四层/距离五层的点数及覆盖计数能加回原全人口（0.435秒、退出0）；语义审查补明baseline singleton的编码器支撑不等于物理补全。这些是合成行为证据，不是真实MTAD效果。
