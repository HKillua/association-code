# 089：失败增强配方的训练物理初值重放

089 是一次独立CPU输入诊断，原083固定p=.5配方保持关闭，不补seed或搜索概率；也不是086—088训练的前置。研究问题仅为：**原083实际成功更新所使用的删除操作，改变了多少物理初值、可用支撑与原训练平均损失系数？** 不估计083最终V退化的因果解释比例，不训练新选择器。

## 来源与不可越界输入

读取原083、072C的完整`run.json`、`execution.json`、`fit/run.json`、`fit/training.jsonl`及083完整`preparation.json`。按实际配置、来源、成功更新数、初值配对历史记录和完整训练人口绑定，禁止拿Git裁剪摘要代替完整日志。原execution所指manifest/alignment/config必须仍可读取且内容相同；若清理过，服务器只能恢复原冻结配置，不用其他版本替换。

请求的archive有序列表必须分别与083和072C原`execution.arguments.archive`经过`Path.resolve()`规范化后完全相同；缺失、换卷或换序在读取原始数据前拒绝。允许解析到同一原文件的路径别名；不通过SHA/hash建立验收门槛。若原卷迁移，先保全迁移依据并恢复原路径到原文件的映射，不能静默替换成同节点但坐标不同的数据，也不能修改历史execution以通过检查。路径绑定防止无意改源，不证明原路径内容从未被外部修改。

新入口对照当前冻结083配置与Level1 manifest/alignment，只重放T_core。其流式数据链为：原生T量测/标签→同cap128/Q64/time20适配→canonical_all运动证据→显式offset/gap/shortest_arc的T参考。不得调用混合T/V的`load_timed_dataset`。不读取V或T_test观测、参考、预测，不加载checkpoint、不构造模型、不前向、不优化、不关联评分/阈值选择/预测分组。

历史训练成员的重建需要每场固定OLS轨迹距离，以重现`training_members`选择的那个错误helper；这是原T样本构造的确定性重放，不产生新预测分组。真值身份只用于原T模式及事后诊断，不参与删除随机数。

## 两阶段核验

1. **成功日志原序回放。** 原scene/anchor RNG与独立增强RNG从各自冻结seed开始，按全部4000更新×8样本原序核验。原batch必须逐项相同，删除mask、保留成员、增强RNG前后状态、成功曝光合计均闭合。零监督样本不被删除。
2. **按场景重建。** 流式读全部T_core2100场，核原preparation中的节点/原生点/候选及目标人口、input/quarantine审计、参考对齐及各属性有效点数、motion原生点数、参考成员路径/行数/问题数与量测成员路径；再核原成员/节点ID、eligibility和删除前后完整`dropout_audit`与日志一致。仅当前场缓存重复成员的物理初值，处理后释放。原日志未保存逐点mask数组，因此本项核验是重建mask与原有效计数/配置/原数据的绑定，不冒称与不存在的旧mask数组逐位重放。

初参数逐值相同引用原083配对证明，本项不读取权重重新证明。若任一输入不足、来源不同、日志截断、计数/RNG不一致，失败保全并停止，不缩小人口继续。

## 输出与权重

对同一T参考分别计算完整成员与删后成员的fixed.95位置初值误差；两初值位置距离亦用Haversine。每个有监督样本的第i点系数为`1/(4000*8*n_valid)`；原线性目标使用公里误差。无有效点样本贡献0，但仍占原batch/全局样本分母。

分别报告：

- 重复有效点频率：全局及原/删后0、1、≥2支撑helper。
- 实际样本等权loss系数和以米/公里表达的误差贡献；系数质量可能小于1，差额正是零监督样本比例，不重新归一化。
- 原/删后prior的点MAE/RMSE、绝对误差和/SSE、两prior几何位移和；删除相对完整prior的H/I及其系数贡献。
- 单列全部查询（包含无有效参考和零监督样本）的prior几何位移总和/均值；分母为全部查询数。它不增加有监督误差人口，不生成参考误差或loss系数，并验证原机会区之外的物理初值逐值不变。
- 原支撑区（anchor内／anchor外helper有／全组无）×训练mode×原/删后helper数量的互斥交叉表。空单元保留0/null，所有单元共享全局分母；加法字段还原总量，条件均值不相加。
- 全部逐场人口、未曝光场景、零监督曝光；另列已曝光场景的点均值等权与样本均值等权描述。场景等权仅作为总表，不扩入交叉表；交叉表保留全局样本loss分母及点频率。重复查询/片段曝光不当作独立样本。

不报告P95/P99，因为本轮不保留全量逐点误差分布，也不从各场分位数拼出全局分位数。H/I是这两个物理候选的误差加法分解；不是模型训练因果贡献，不是梯度或Adam更新量。
