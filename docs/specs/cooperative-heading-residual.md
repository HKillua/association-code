# 032后的航向观测残差：本地候选规格

2026-10-20；依据[031/032完整结果](../proposals/repair_before_retraining/031-032-analysis.md)，回答用户“32怎么改，本地不能只等33”。这是可选候选实现；用户已明确“批准034，与033独立推进”，授权一次单卡1000步及完整V评价。033已完成，旧032配置与权重语义不变。

**研究问题：** 航向观测中有可用信息，但032直接预测绝对方向，完整V误差89.92°，原量测控制55.94°。检验显式保留观测航向、学习角度残差是否优于绝对方向头及原量测控制。仅加入这一种输出结构；速度仍为032的scaled_log、位置及原teacher self/cross/BCE目标、采样/裁剪/预算不变。现有decoder已经接收query时刻及邻近支撑信息，不将近常量输出描述为“代码没给时间”。

## 行为约定

- `heading_output_policy`缺省`learned_absolute`，保持旧公式、初始化、旧checkpoint加载；新`observation_residual`只支持v2。
- encode仅从当前可见native token反归一化得到度数，保存`native_headings`；不读query状态、reference或helper身份。缓存与切片必须同步保留该字段。
- 对当前anchor在query时刻计算观测底座：相邻可见点取最短角弧插值，180°附近按原始差值正负选弧，支撑外保持对应端点；训练裁剪后重算，不偷用被移除的点。
- 新policy的半周数值容差固定为`8 × finfo(dtype).eps × 360°`（FP32约.000343°），只用于处理反归一化令180°微偏后选反弧的问题，不改旧位置/数据插值规则；在该极小邻域内按原差符号取半周，明确不是由真值决定转向。
- 输出为`wrap_360(heading_base + state_std[3] * residual)`，不加原均值；保持原角度残差尺度和loss。允许观测时刻有非零修正，不把带噪观测永久锁死。
- 新policy仅航向输出行/偏置清零，使初始化等于观测底座。其它参数、模块构造与随机数消耗保持。**底座与中性初始化是这一结构改动的共同部分**，不能把后续收益完全归因某个单一算子。
- self、cross和group都用`members[0]`的观测底座；helper只沿现有上下文路径影响残差。交换anchor时目标也交换，不使用helper原方向直接代替anchor。
- 新头使用明确的配置和对应state标识；拒绝把旧032参数静默换公式解释。需要新训练，不做热切换或自动续训。
