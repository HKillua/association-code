## 原生事件与匿名来源

- 从现有canonical原始事件读取全部点，无新增截断、切窗、插值或人为遮挡；固定T2100/V300、056组、Q64、原target/mask和全人口。
- 事件ID为加载器原node_id及canonical索引；重分段视图必须携带原ID。只去掉重复ID引用；不同节点或来源的相同数值不能合并。加载器未提供CSV行ID，因此不宣称跨batch原始行去重。
- 来源标签仅用于形成匿名等价类，编码/patch query/解码器全部共享。给定同一b和同一事件池，来源重命名、排列、重分段应保持结果；旧b依赖anchor，不能扩大为整个系统无条件不变。
- 8个等物理时间patch，边界来自本场Q首尾；边界外可见事件放首/尾patch，不丢掉。原生时间与Q时间均为真实秒，20秒仅编码尺度。
- 无效属性先清零并输入mask；空patch不提供证据；全空精确返回b。reference/身份标签只用于训练目标与既有采样，不能进入事件模型。
- 位置事件使用可见底座决定的局部北/东公里特征，航向用sin/cos，速度用原生数值的`log1p(v/10)`；这里是固定输入尺度，不把尚未核定的原生速度单位改称米/秒。

## T实现与来源

[QuITE论文](https://proceedings.mlr.press/v306/lim26b.html)提供单层可学习query汇总不规则事件的机制。独立实现，不复制作者整仓。原指定实现存在key mask错轴：本实现使用正确key padding mask，并继续屏蔽空patch。只计算单层汇总query行，与该层完整自注意力的汇总行等价，不宣称完整QuITE++复现。

T2为共享64维、4头的单层query聚合；T1为固定均值池化及活跃MLP，报告参数差。两者使用相同物理特征/时间编码、patch边界、共享实际Q解码器与来源对称池化；二维输出头零初始化，结果是冻结b的米制切平面残差。速度/航向保持b原输出，结论限于位置。两臂使用同seed，共同模块先构造并逐张量核对。

训练只优化新模块；T0额外优化整个原Transformer。各分支用相同batch、损失与更新数，不声称参数量、FLOPs或优化问题相同。冻结b只读，保存源权重与新权重，加载后独立评价固定final；不重复生成完整initial V，已有090C端点就是共同初始控制。

## R/S最小数学核心

R用共同局部米坐标，目标为`||Σwμ||²+Σw(r-||μ||²)`、`w≥0, Σw=1`。不将估计矩阵强行PSD化。首版风险候选应是固定来源OLS；同T训练过的b只作控制/回退，若把b纳入风险池须先解决训练内误差的乐观偏差。风险回归平方误差，不以log-risk反变换冒充条件均值。R2P复用凸包投影，风险未训练时不能声称概率校准。

S对真实不规则时间构造二阶差分，实际求解有界二次规划，不将无约束解clip后冒称解。λ=0或r=0精确返回b；每坐标r对应欧氏上限√2r；未收敛回退并记录。共同球面log/exp坐标互逆，不拼接两个不互逆的几何函数。先T侧固定网格CPU机会判断，尚无本批真实执行。
