位置点覆盖为 285,721 / 454,952 = 62.80%；轨迹覆盖为 5,797 / 9,099 = 63.71%。位置唯一目标 MAE 1,994.20 m 是已覆盖点上的条件误差，不能与全片段 MAE 2,460.82 m 直接相减。唯一 reference 全不可用身份是场景 4410 的 `371971000-1`，已有 anchor 输出，不属于 3,302 个未覆盖目标。

因此已经有直接证据表明：**按当前 `anchor_identity_first` 对应规则，错误混合分组使大量身份失去独立输出。** 不能把这些损失归咎于没有观测或融合数组无效，也不能扩大解释为“任何几何重匹配都救不回”。3,302 个身份在相关混合组中共出现 4,255 次，不能按出现次数重复计失代。054 将逐数组复核此结论，进一步量化融合收益/伤害和 singleton 恢复覆盖的重复代价。

## 固定的三个控制

| 名称 | 分组与实际系统输出 | 作用 |
| --- | --- | --- |
| `ols_mean_supported` | 保存的 OLS 分组，每组第一节点对应的原保存 mean 输出 | 原完整系统，先精确复算原报告与数组 |
| `group_anchor_ols` | 保留同一分组，每组只输出第一节点的原 native OLS | 与原系统直接分离物理融合影响 |
| `fragment_ols` | 每节点单独一组，输出自己的原 native OLS | 诊断分组引入的覆盖损失，并显式统计重复输出成本 |

三者不使用 reference 生成预测；真值仅用于评价、归因与分层。仍按固定输入顺序选择每个身份第一个 anchor 组，不改为误差最小组，也不把有效的晚出现重复组偷偷顶替无效首组。singleton 是控制，不预先命名为完整系统上界或胜者。它与原分组 anchor 的对比还可能改变代表片段，须报告 same/changed representative 分层。

原 053A 的 per-fragment mean 在无支撑或圆周均值退化时各节点回退自身 OLS；实际系统却每组只输出第一节点对应值。054 的 `fragment` 保留原视图供 replay；**主要片段对比用 `emitted_fragment`，三个方法均将实际组输出广播到组内节点**。不能把两种视图混着相减。`ordinary_fusion()['anchor']` 是逐节点自身 OLS，不等同于本轮组 anchor 控制。

## 归因和指标契约

每场、每个属性分别按顺序给互斥原因：reference 不可评 → 已覆盖 → 无保留输入节点 → 有输入但没有本身份 anchor（错误混合导致失代）→ 所选输出该属性完全无效 → 有输出但与 reference 无有效时刻交集。position 要求纬经同时有效，速度、航向各自使用有效性。

完整人口 = reference 不可评 + 可评人口；可评人口 = 覆盖 + 四类未覆盖；缺失点再按无输入、无代表、代表对应点无效拆分，必须与原报告逐场/全库一致。涉及混合组、外身份 anchor、重复组及晚出现重复输出有无有效交集另外保存为可重叠标记，绝不直接累加成总原因。重复组是额外输出代价，并非所有未覆盖目标的成因。

- 系统主指标保留所有目标及重复预测行；分别报告位置 m、原生速度单位、圆周航向度的点/轨迹覆盖及 MAE、RMSE。
- 三对方法分别取同一目标、同一时刻、同一属性的共同有效点。只取完整 registry 的目标行，不用重复行创造额外真值；保留全部真值分母，零交集误差为 null。
- 汇总按点数合并误差，同时给场景等权 MAE/覆盖及实际参与场数。不存在交集的场景不填零，不平均各场 RMSE。
- 主分层固定使用每个真实身份全部原输入片段的 support 并集与 nearest 最小值：支撑内/外、精确观测/非精确观测、≤300、300—600、600—1800、>1800 秒及无输入；此身份操作仅用于事后评价。
- 原 `input_support_metrics` 仍保留为预测组上下文。尤其 anchor 控制的 helper 支撑**不是它实际使用了 helper 的证据**。它不能替代上述固定人口分层。
- 共同点另报告改善/恶化/持平点数、收益/损害总和及逐点误差差值；1e-9 原生单位仅作数值持平容差。固定组 mean − anchor 为正表示融合增加误差。组伤害的覆盖损失与融合的条件 MAE 不能直接相加。
- 重复输出组数和其中有效预测点/轨迹单列；`prediction_without_target_count` 还含 reference 无效时间点，不能全部叫重复。

## 决策顺序

1. **已有证据把“错误合并造成失代”提升为实质瓶颈。** 054 用 singleton 对照确认可恢复多少覆盖、代价是多少；研究应关注拒绝不可靠连接/保留独立输出，不能只追求关联 F1 或减少输出数量。本轮不改阈值、不训练新分组器。
2. 固定分组的 mean 与 anchor 若显示广泛污染，则融合也有独立研究空间；若均值大多有益，则不因为个别坏例强行设计融合网络。相反，anchor 几乎处处占优时先保留简单控制。
3. 目前仅保留[一个有条件的混合收益候选](2026-10-21-054-mechanism-note.md)，并行完成机制分析，不启动训练。如果关联失代主导而融合收益空间不足，暂缓它；不同时拼出第二个复杂候选。新 Level1 关联/融合 pilot 的具体设计、预算待 054 结论再决定。
4. TMTAFF 仍未成功复现。053B 已看到 encoder 条件差异衰减和 decoder 进一步压缩，但因果根源仍待证；当前不能用退化 TFM 证明候选胜过论文。B 线只读机制分析见同一说明，不新增服务器 forward/backward 作业。
