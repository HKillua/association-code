# 数据集选取与基线差距：证据审计

2026-10-27。回答两个问题：固定的 MTAD Level1 3000 场景是否适合继续研究；现有结果与基线相差很大，能否归因为选错了数据。本文是对已有协议、名单元数据、论文正文核读和已完成实验的审计，不是新实验、方法选择或执行状态表。目标与排期仍只见[研究状态](../research_status.md)，数据规则仍只见[数据约定](../data_contract.md)。

**判断：保留现名单用于开发阶段的同任务比较有合理性；它不能支持“已按作者协议复现 TMTAFF”或“对未见船舶独立泛化”的主张。现有证据也不支持把巨大差距主要归因于抽到了坏数据。** 有些差距是指标与任务不可直接对照，有些是本地适配在共同有效点上确实失效，还有些涉及尚未明确的生成语义和极端案例；必须分别处理。

| 项目 | 本次界定 |

## 2. 为什么是 Level1、3000 场景和 7:1:2

**DE：Level1 是明确的项目选择。** Git `91ecbe5` 的 `HandOver/Handover.md` 第 3 行记录，2026-10-21 用户决定正式实验使用 Level1、停止 Level2 路线。两包此前标签审计各有 5000 场景、15000 CSV，共享 26221 个原始 A 身份；同编号场景的 A 和 A-B 集合并不相同。因此不能用 Level 名称认定难度、独立性或训练/测试角色，也不能把 Level2 编号和统计直接搬过来。[数据约定](../data_contract.md)

**SC：3000 和 7:1:2 对齐了 TMTAFF 报告的场景规模与比例。** 其正文 p16 §3.1.1 写随机选择 3000 unique scenes，再按 7:1:2 划分。这支持采用 2100/300/600 的规模参照，不能恢复其具体样本。公开材料没有给出本地对应 Level、完整名单、划分种子或足以重建全部预处理的信息；论文 seed20 指权重初始化，本项目把 20 用作划分种子是自己的选择。[论文协议](../mtad_data_protocols.md)；[正文重审及页码](/Users/a1/Projects/biye-ronghe/docs/surveys/2026-10-26_mtad_actual_use/tmtaff_reaudit_20261027.md)

**UN：没有依据证明 3000 是该研究问题的最优样本量。** 未见针对效应大小、独立组件数或物理场景覆盖的样本量论证。现有依据是论文规模参照及固定的开发协议；这不等于“只用 3000 才正确”，也不构成按已有成绩扩充或重抽名单的理由。

**DE：当前抽取规则可复现，未发现按模型成绩挑场的步骤。** [生成代码](../../association/data/scene_manifest.py)先读标签构造共享 A 组件，将已预览的 scene0 固定在训练侧；其余场景按 `SHA256(str(seed)+':'+scene_id)` 排序，依次填 T_core、空 T_head、V_select、T_test，余下未用。组件只用于依赖披露，不作为隔离边界。此次用标准库独立重建排序，四个 split 的集合均与现名单完全一致；场景 ID 跨 split 无交集。此前 scene0 仅预览过关联/量测/reference 各前 600 字节，训练侧保护有明确来由。

这是一份按预先固定种子生成的场景级名单。排序与无成绩筛选可以减少人为挑场，但不能证明任务难度均衡或物理代表性；也不能把 scene ID 不重复写成原始身份独立。

## 3. 有多少真正独立的信息：名单复算

以下均从[现 manifest](../../configs/data/mtad-level1-scene3000.json)的集合和组件映射复算，原始标签未重读。

| 划分 | 场景数 | 涉及共享 A 组件数 | 最大组件在该划分的场景数 |
|---|---:|---:|---:|
| T_core | 2100 | 84 | 966 |
| V_select | 300 | 38 | 130 |
| T_test（仅名单） | 600 | 60 | 240 |
| 全包 | 5000 | 119 | 2204 |

- **DE：58 个组件跨正式划分。** 已有标签审计记录 T/V 共享 6053 个 A 键、T/test 共享 8634、V/test 共享 3437，`identity_independent=false`。A 对应原始 MMSI，监督身份是 A-B；上述数值不是重复 A-B 实例数或重复量测数，不能据此量化模型记忆、泄漏收益或误差影响。
- **DE：验证场景集中于少数组件。** 最大两个组件在 V 中分别有 130 和 59 场，合计 189/300＝63%。因此报告场景等权和组件分层有必要；300 场不代表 300 个完全独立来源。组件重采样也不能消除反复开发及跨 split 来源依赖。
- **DE：封存并不自动等于身份独立。** 现有 600 个 test 场景中，与当前 T 和 V 均无组件交集的只有 9 个组件、10 场。此结论只读名单，不意味着已经评价这些测试样本。
- **DE：2000 个 unused 不能直接当新身份测试池。** 与当前 T/V 组件均不交的 unused 仅 28 场；其中与所有正式 split 均不交的是 25 场、24 组件。历史 Level2 开发还存在共享来源身份，故“对当前 T/V 组件不交”仍不等于“对全部开发历史独立”。

**AI：现名单适合研究这批既定场景上的开发差异，但身份泛化必须另立协议。** 不能用现有标签依赖直接断言所有成绩都无效，也不能忽略依赖，把 query、场景或训练 seed 包装成独立数据重复。未来若要主张未见身份或外部分布泛化，需要先确定隔离单位、历史暴露边界、可用独立来源及评价终点；不能在反复使用 V 后简单改名为 test。大型连通组件也会约束划分规模与多样性，须在新协议中权衡。

## 5. 为什么与 baseline 差很多：已证实的三类区别

### 5.1 本地输出与论文表：有些数字本来不可直接相除

**SC/DE：论文 mME 是有符号均值，当前位置 MAE 是球面米制绝对距离。** 经纬度 mME 的单位为 10⁻⁴ 度，正负可抵消，还涉及目标→场景的聚合；它不能与米制 MAE直接对比数量级。论文 mESD 的印刷公式与标准残差 SD 存在定义歧义，实际作者程序未取得。关联 mPCA 是召回口径，也不是 macro-F1。统一列名和单位有必要，但仍不能消除人口、时间窗和实现未知。[指标定义](../mtad_data_protocols.md)

已有 101 就显示：090C 经/纬有符号均值约 1.3136/−3.1756，而同聚合坐标 MAE 为 40.6806/30.9163，单位均为 10⁻⁴ 度。均值小不代表绝对误差小。因而既不能据现米制误差宣称输给论文多少倍，也不能据小 ME 宣称已经胜过论文。[101 原审阅](2026-10-26-experiment-review.md)

### 5.2 本地 TMTAFF 适配与普通控制：共同点上的失效是真实的

**DE：096 的差距不只是人口不同或数据太难。** 已完成记录显示，096A 接受约 99.973% 候选边，290/300 场只剩一个预测组，位置覆盖仅 3.3557%，自身可评人口的 TFM MAE 为 58587.02 m。这支持严重误并/覆盖退化，不能作为可信作者方法效果。

更有辨别力的是相同适配评价中的成对共同有效点：**10183 个共同位置点上，TFM MAE 为 59040.15 m，Anchor 为 583.53 m，约 101 倍。** 另一个 15267 点的共同人口上，TFM 为 58587.02 m，Mean 为 42946.66 m。两组人口不同，不能拼成一张三方法共同排名，也不能把 10183 点写成整个 V300 的完整人口。[096 同 mask 对照的 Record/Squeeze](2026-10-26-experiment-review.md)

**AI：同一批可评点已有可用得多的普通控制，故“单纯选错数据”不能解释适配的全部大误差；物理恢复路径也存在明确失效现象。** 这还不能唯一定位到网络结构、补全、损失、采样、训练量或速度单位。失败适配只说明这次实现/协议/预算组合没有形成可信同行，不能反推原论文方法无效，也不能把候选胜过该适配当作胜过 TMTAFF。

### 5.3 原包物理语义与极端样本：真实疑点存在，范围必须保留

**DE：Level1 的输入与 reference 速度不能继续假定同单位。** 固定前 8 个训练场的原生相邻点核验强支持量测 kn、reference 更支持 m/s；这纠正了历史四状态链的单位假设，但不证明全包每条记录的生成语义。位置米制误差由经纬度计算，不会因发现速度单位问题自动作废；多属性训练受到的间接影响尚未做因果分离。[原始核验范围](../data_contract.md)

**DE：所查三个事后选定极端场景中，原始 reference 已有短时大位移。** 105 对固定六个量测节点和三个目标 reference 的原行链核对通过，原量测重建与保留 canonical 一致。这减少了这些固定行的本地读取/重建不一致解释，但不证明物理真值、reference 生成器或整包异常率；不得由三个最坏例推断全部数据不适合研究。[105 原链记录](2026-10-27-raw-case-chain-review.md)

**DE/UN：时间对齐规则有一致性证据，未唯一识别真实时钟。** 既有准备中 179733 个有效片段通过所定时间范围检查；2400 场中 587 场的范围约束不能唯一确定 offset。数据集母 AIS 预处理在生成片段之前，不能当作成品所有时空语义正确的保证，也不能照抄母轨规则删除下载包短片段。reference 的精确生成/平移规则仍未知。[准备统计](../../configs/data/README.md)；[数据与论文协议](../mtad_data_protocols.md)

因此，要保留两条不同结论：按既定 reference 评价的开发差异可以报告；据此宣称真实海上物理定位精度，需要更强的真值来源和时空语义证据。reference issue 事件数、缺失真值和选定案例的大位移也不能合并成一个“坏数据率”。

### 5.4 当前090C与内部控制：位置收益成立，不能外推到四属性

**DE：固定056组和共同可评人口上，090C位置MAE为564.834 m，Anchor为885.579 m，Mean为1224.604 m。** 覆盖为442263/454952＝97.2109%；090C相对Mean的场级MAE在300场均改善，但RMSE只低4.25%，P99只低5.27%，不能用平均收益掩盖极尾。该结果说明当前任务存在可学习的恢复收益；普通控制不是已发表同行，不能据此宣称已超过TMTAFF。[101审阅](2026-10-26-experiment-review.md)；[102复核](2026-10-27-returned-diagnostics-review.md)

**DE：090C只学习位置，速度和航向逐点继承Mean。** 其速度MAE为55.537843 kn，航向圆周MAE为75.936382°；四属性报表不代表四属性都由090C学习。速度/航向的大误差必须定位到这条继承路径及其数据语义，不能都归到位置网络或抽样名单。这里也没有把新单位修订后的模型效果与旧端点混用。[102属性来源与完整统计](2026-10-27-returned-diagnostics-review.md)

## 6. 可以保留的主张与不能支持的主张

| 判断层级 | 现有证据支持 | 现有证据不支持 |
|---|---|---|
| 领域数据选择 | MTAD 提供相关的多源片段关联与状态恢复对象，可继续作为明确限定的研究材料 | Level1 天然比 Level2 更难/更干净；成品 reference 已证明物理准确 |
| 固定名单 | 按确定规则选 3000 场，scene0 历史暴露受到保护，可重复做同人口开发比较 | 名单就是作者名单；3000 为经论证最优规模；场景级无交集等于身份无泄漏 |
| 开发效应 | 在相同信息、组、query、目标、单位和共同有效点上比较，并同时保留全人口、尾部与覆盖 | 用不同人口 MAE 排名；用 oracle/固定组结果冒充完整系统；把反复使用的 V 当独立测试 |
| 基线差距 | 096 在同 mask 下也远弱于普通控制，失效不只表现为误并；有明确待核适配因素 | 由失败适配认定 TMTAFF 无效或候选胜过作者；把所有差距归为单位、坏数据或训练不够中的一个 |
| 泛化 | 披露共享 A 和组件集中，评价这批既定开发场景 | 对新船舶/新分布的独立泛化或普遍显著优势 |

## 7. 最小修正与可执行的后续步骤

以下是本审计给出的行动依据，不是训练额度、方法选择或服务器领取清单。

1. **保留当前名单与难例。** 固定 Level1、T/V/test 角色及完整目标分母，不因成绩不好重抽、改 Level 或删除三个极端场景。现有结果保留原协议解释，不用后来的筛选追改旧主表。
2. **先验收共同比较的数据链。** 对新单位准备产物核场景、片段、候选正负对、reference 逐属性有效人口和实际训练呈现条件；与旧记录有差异时先定位，不直接归为模型效果。新的输入 m/s、reference m/s 与论文输出 kn 的转换各自明确，不能缩放旧权重冒充重新建立统一单位的模型。
3. **把控制接到同一评价人口。** 按[固定056比较合同](2026-10-27-fair-comparison-contract.md)，同时保留 canonical_all 与参考模型实际 cap128 的普通控制、全人口覆盖、成对共同有效点、米制误差/尾部及论文维度；固定关联条件与完整系统结果分表。论文 ME/ESD 未知不妨碍做清楚的同任务实测，但限制“精确作者复现”的名称。
4. **用实际准备与既有失败证据讨论训练方案。** 讨论需要覆盖的场/轨/正对、监督点、固定终点、成本与停止条件，区分受限可行性诊断和充分的同行比较。没有证据证明原来的 1000 更新或一遍 TCM 已充分；也没有证据证明直接加步就能解决。这里不选新方法、不确定训练预算。
5. **将身份独立及物理泛化评价另定。** 若后续主张需要未见身份或真实物理精度，先确定可获得独立来源、历史暴露边界和 reference 依据，再冻结新的评价协议；当前 unused/test 不能直接提供充分身份独立样本。不得先看新评价成绩再决定名单或窗口。
