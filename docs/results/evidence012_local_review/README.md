B的全局排序高于A0，说明不能从其已选工作点F1更低推断“输出完全失去判别信息”。但打乱第三片段的B_shuffle在AUC/AP上仍略高于B，EndpointMarginal的AP也高于B；现有数据仍不支持联合第三片段机制的专属贡献。AUC/AP是全局排序，macro-F1是场景等权且有阈值，优化对象不同；**不能据此把失败全归于阈值，也不能事后换一个指标宣布成功。** 原heads本来已在V上选阈值，当前没有进行“补救式”重选。
