## 3. 融合：先同时看误差与覆盖，再做共同支持对照

这里的“已观测区”是同一目标各片段端点时间范围的并集在64点查询网格上的支持，可包含片段内部插值，并非每个点都有原始实测；“缺失区”是该支持之外的查询。17062/1302是reference有效查询点数，不能据此统计内部原生量测缺口。

下表位置MAE只在各方法自身预测与真值的有效交点计算。不同覆盖不能直接排名。oracle/单源/简单融合使用真实身份，属于诊断对照。

| 真实身份＋神经融合 | 12,901.00 km | 18347/18364，99.91% | 377/377 |

两个更有判别力的比较：

1. **已观测区完全共同的17062点**上，oracle神经融合MAE为12854.79公里，而简单融合为1797.14米。这个巨大差距不是交点不同造成。
2. 同目标、两侧都输出完整共同网格并覆盖相同reference位置的110个多轨目标、5453点上，预测分组与oracle均约13519.4公里。不能只把异常归罪于关联误并。

进一步拆开真正调用网络的组：358个oracle多轨组的组级MAE**全部超过1000万米**。其中42个恰好二轨组只调用一次TFM，点加权MAE13497.88公里；19个oracle单轨组透传826个输入支持查询点，MAE仅约1.6×10⁻⁹米。错误不需要多轮递归才出现，也不是所有方法统一单位错位。

缺失区有1302个可监督位置点，分布在193个目标实例，占全体真值点7.09%。预测系统覆盖403/1302点、67/193目标，MAE13504.97公里；oracle覆盖1285/1302点、190/193目标，MAE13514.65公里。简单融合及两个单源在缺失区不输出，误差应为null，不能记0。**当前模型能产生缺失区输出，但没有学会正确恢复。**

9001的总体0.348米几乎全部来自scene2882的81点（场景MAE64.18米），其余63场景接近浮点零。结合既有原生reference复用审计，已观测区降噪收益空间受限；这不等于缺失区恢复无价值，也不允许人为加噪构造优势。

## 4. 找到了什么问题，什么尚未证明

完整推导与源码链见[模型诊断](model_diagnosis.md)，CPU可复算证据见[model_geometry_diagnostic.json](model_geometry_diagnostic.json)。

**确定的实现事实：** TCM输入标准化，但TFM最终LayerNorm后直接线性输出原始经纬度；输出头Xavier、零偏置，从近零尺度开始学习。原生训练输入经度均值130.9900°。论文TFM段落也讨论原始物理量损失，因此这不是“漏了一个原作者明确要求的反归一化”的证据；它是当前近似实现与训练设置的数值不匹配。

在当前fresh初始化、最终post-LayerNorm、Adam(.85,.99)、无weight_decay、指定学习率及阶段更新数条件下，可对任何输入推导**网络生成坐标**的保守实数算术上界：

| 训练量 | raw经/纬度绝对值上界 |
| --- | ---: |
| 当前TFM2，lr .002 | 28.0292° |
| 未批准模板TFM100，lr .002 | 122.1730° |
| 上述100＋新Adam JOINT20，lr .0002 | 123.7865° |

该推导已独立复核，说明不能直接把旧100/100/100/20模板当作合理参考训练方案。只增加少量步数，甚至仍无法输出训练地理中心附近的经度。**限制：** 输入均值不是全部验证reference的下界；未取得服务器权重，不能给出每个目标的精确不可达误差。该界不是CUDA/FP32逐位证明，不约束单轨透传或简单融合，不表示更长训练永远学不会。

**按用户本轮“找到问题直接改代码”授权修正：** 引入显式train_position_affine输出，仅用训练原生输入的固定经纬度mean/std把位置投影还原为物理坐标，速度与航向沿用原映射；物理loss、模型参数规模及三个模块保留。raw默认和旧检查点行为保留，历史013/014结果不重算。规格及验证边界见[输出尺度修正规格](../../specs/tmtaff-output-conditioning.md)。新名称为“TMTAFF时间与输出尺度适配近似参考”，不能冒充作者精确实现。这项修正不自动批准正式训练量或新GPU预算。

**速度数值边界：** 训练速度mean约109、std约415，若使用四维affine，速度投影−1会使softplus输入约−306并在FP32饱和。因此最终参考修正仅处理经纬度。候选现有四维映射也有这个可能风险，015需观察真实速度输出；目前没有证据证明真实候选已经饱和，不据此改其已批准配置。

**其他风险仍在：** 关联排序弱与误并、只有两次有效TFM更新、递归memory与训练成对特征分布不同、按关联F1选全系统快照并不保证物理融合最好。输出尺度修正只消除已定位的数值门槛，不能保证这些问题一并解决；尚不改变采样、递归、选模或阈值。

## 6. 回执纠正、验证与局限

- S2L称选中融合含TFM2＋JOINT2，原件实际只有TFM2；称untrained也不严谨，应为极少训练。
- preparation_extract的nodes/candidates/targets等人口0为缺键提取错误；实际人口已由完整结果复算，不能接受默认0。

- 80–88°航向MAE不证明输出服从随机分布；起始GPU空闲快照不证明全程独占。
- predicted低于oracle的全域MAE不证明错误关联有益；“prediction_without_target”还包括超出reference有效时刻的输出及重复组，不能全部当作错误身份目标。
