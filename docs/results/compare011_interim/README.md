4. `missing_comparisons`只描述CDF入口本身不加载A_full/TSA；A_full与TSA已在本报告独立复算，不能据该字段说它们尚未完成。

A_full与A0/TSA的场景、节点、身份、候选、标签、来源和时间区间逐项相同，**仍是29008对**。中期“29001/28985候选对”现已确定是口径误读：原history中两数都是`selection.candidate_count`，即不同分值数＋一个全拒阈值。最终缓存有28984个不同分值，加全拒阈值正好28985。阈值`>=`包含相等分数，没有因同分丢边；非有限分数会报错，也未发现子集变化。

A0→A_full纠正2005条原错误、新增11552条错误，**净增加9547条错误**；其中纠正FP1182、新增FP11409。A_full接受90.26%的配对，micro-F1仅比全接受参照高0.006188，当前判别效果很弱。但服务器“每项指标都差于A0”不准确：其Recall从73.40%升至94.02%，代价是FPR从50.01%升至89.78%。

## 结论与下一步

三项执行均已结束，未追加训练。当前结果是：TSA离线适配提供了更强的实测比较对象；CDF1本轮汇总未显示收益并明显增加错误；同样短训更新量的A_full也更差。CDF1尚需完整分数完成逐边复核，A0/TSA/A_full全量与共同子集结果已经从缓存复算。

接下来只补回CDF七臂既有缓存，不重训、不重新推理、不新增关联分支。当前负结果不能包装成候选成功，也不把CDF1锁定为最终创新。

全课题下一步按[研究说明](../../research_brief.md)推进不完整量测下补全、关联、融合的完整近似参考：补齐时钟与监督、完整分组输出和融合评价，再形成具体训练方案。已有TFM组件的合成测试不等于完整系统实测，011未用预算不自动转成融合训练授权。

零正例场景误触发率仍不可测；单seed、验证集选模、优化量不等和原论文适配差异继续披露。训练充分性、表征与实现选择分别贡献多少，现有结果不能作因果拆分；T_test继续封存。
