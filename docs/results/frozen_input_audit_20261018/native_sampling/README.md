## gap180零监督与真对采样

只联结已有[监督身份结果](../supervision_gap_zero_targets_20261018.json)，不重读reference。57个四维全零身份全部有有效轨，53个产生正对，共213轨、366正对。[gap180_sampling_risk.json](attempt2/gap180_sampling_risk.json)含逐身份与逐场景计数。

若场景有P个正对、Z个来自全零身份，B批在P≥B时全零概率`C(Z,B)/C(P,B)`，P<B时`(Z/P)^B`；再对512个正例场景平均。TFM B64每步约2.954e-38，joint正例B32约2.465e-32。不是0，但不能把57个零身份说成必然导致整批失败。这只描述固定人口/分布，不保证其他模型/数值步骤成功。

当前各2更新提案的TFM与joint均未抽中零监督正对、整批全零0。90/95/99%阶梯TFM有169/232/412次零监督真对呈现，joint有93/123/195次，均处于混合有效batch，整批全零均0。`fusion_training_step`按整个有效batch汇总feature counts，局部微批允许零贡献；pair_microbatch=1不等于“任何零监督pair都会报错”。不删除身份、过滤pair或重抽样。gap600已有576场景结果表明每标签身份每feature至少1个监督query，本次不重复证明，也不自动批准gap规则。
