# MTAD外部公开处理流程与本项目对照

2026-10-19。用户要求联网查找MTAD开源处理以定位实验问题。本轮完成网页/GitHub检索、两个相关仓库实际源码检查、官方客户端静态读取、八篇论文处理段复读和本项目生产路径核对。没有执行外部程序、下载其数据集/权重、读取任何测试CSV或本项目T_test，也没有训练、修改数据处理代码或改变017配置。源文件只保存在本地研究证据目录，没有将第三方代码复制进本仓库。

## 结论

**有公开代码，但没有查到一套可直接充当TMTAFF官方标准答案的完整预处理流水线。最有力的新信息是：不同工作虽然都称“使用MTAD”，实际使用了不同的数据再生成、时间范围、轨迹保留与匹配任务。** 本轮未确认新的CSV列/单位单边换算/身份/时钟接线错误；已明确当前全场景Q64是我们自行补出的适配设定，而非TMTAFF公开给出的确切窗口参数。代码测试通过不能证明这一研究设定合理。

## 2. 论文处理方式为何与我们不等价

| 来源 | 已公开的处理边界 | 与当前处理的区别 |
|---|---|---|
| [TMTAFF](https://www.mdpi.com/2076-3417/16/14/7251)，PDF pp.5–8、15–17、29 | 所有轨迹补全到预定义共同Tstart–Tend；长度64；长连续轨迹随机截断增强；离线可用未来观测，外推越远越不准 | 没给可还原的窗口秒数、步长、最大补全跨度及完整loader。既不能断言作者仅用短窗，也不能把全场景min/max→64视为其规定。 |
| [TSA-cTFER](https://www.mdpi.com/2072-4292/16/18/3380) | 最大128点，超长可保留最近点，pad/mask、20秒在线更新与时间/空间候选筛选 | 我们cap128遍布原轨按索引均匀抽样、全候选离线评价，含更多不同任务条件。 |
| [CA-LSTM](https://www.mdpi.com/1424-8220/25/11/3465)、[PTFM](https://www.mdpi.com/2079-9292/14/17/3461) | 时间交集对齐后切窗；CA-LSTM比较10–50点窗口，PTFM使用已关联轨迹对进行融合 | 其匹配或融合指标不包含当前所有短片段、无支撑时段及预测分组覆盖失败。 |
| [MH-T2TA](https://doi.org/10.1631/FITEE.2400340)、[CIAG](https://doi.org/10.1049/rsn2.70044) | 清洗母轨再派生传感器数据；关联网络采用60秒窗口 | 不是把下载包的全场景轨迹全部作为一个补全范围。母轨>600秒分段也不是我们reference gap600的论文依据。 |
| [Homography](https://doi.org/10.1049/rsn2.12483) | 统一周期后取近期少量点、减场景中心、两源一对一场景匹配 | 输入、中心化、身份多片段与监督方式不同，不能直接混排分数。 |

## 3. 当前问题分成两类

### 时间任务的适配假设需要优先复核

[当前grid](../../../association/timed_inputs.py)对场景所有有效片段的最早到最晚时刻均匀取64点。候选teacher用采样到的每条单片段恢复同身份在这条整场景时间轴上的合法reference，并没有按离可见观测的距离限制监督。017的TCM训练原生相邻点转换，应用时却可能需要较远query的递归外推。**20秒是时间编码单位，不是Q64采样间隔。** 刚完成的候选v2修正表示/底座并加入机制，仍沿用这一时间任务。

已审3固定V场景的74片段、3762个合法query中，66.96%在片段自身支撑之外，31.77%离支撑超过30分钟，10.63%超过60分钟。这仅是已审样本，不代表全部训练池或实际采样频率。[原有分析](../dataset_followup018/README.md)

由此能推断：任务很可能比“邻近缺点恢复/局部关联”困难，训练的近邻转换和应用的远端预测也可能不匹配。**这还不是处理错误已被证明，更不是缩短窗口必然提高有效研究结论。** 我们此前采用全场景范围时缺乏作者确切窗口依据，应明确承担这是适配假设，不能用软件测试替它背书。

### 长时外推解释不了全部基础恢复失败

018在同一oracle已有支撑、17062个共同可评点上，模型位置MAE仍约55–56公里，简单融合约1.797公里。[018复核](../cooperative018_local_review/README.md) 因此不能把全部低分归于外推、再只展示短窗好看的子集。新v2的观测底座、速度输出及航向表示针对部分恢复风险，但尚无真实训练结果。

此外，我们训练侧拟合归一化、明确mask、A身份隔离和保留全部有效短轨，与某些外部项目的轨迹筛选、再生成及持出侧统计混入路径不同；这些不是应当撤销的处理。原生9001/reference部分点复用限制了已有观测降噪空间；其他作者重新仿真两源，并不构成我们未经确认加噪的授权。

## 4. 下一步建议与执行边界

**后续训练侧分析已完成：** [21分钟方案的覆盖与任务代价](../time_task_analysis20261019/README.md)。当前推荐已调整为保留原任务检验已实现v2，不把21分钟切窗设为开跑前置；以下原建议保留其问题动机，不作为待实施命令。
