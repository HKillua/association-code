## 四臂与共同状态

- 四臂为位置保持／非等间隔 CV-KF 预测 × 互为唯一最近／带显式空配的全局最小成本指派。门内成本统一为到目标位置代表的平面平方距离，门上界 4000 m，每个未配端成本 `4000²/2`，只接收严格改善空配成本的边。局部控制一轮互为唯一最低，不回填。全局保留在全部最优解中伙伴一致且具有正收益的边，未定者维持独立。门、代价、生命周期和读出固定。对照同一规则产生候选，身份历史受处理影响，另报初始及事件层竞争规模。
- 两轴独立位置/速度滤波，`F=[[1,dt],[0,1]]`，白加速度 `Q=q[[dt³/3,dt²/2],[dt²/2,dt]]`，`q=0.1 m²/s³`，位置 `R=150² m²`，初始位置方差 `R`、速度均值 0、方差 `12² (m/s)²`。实际相邻报告间隔更新。两种运动臂对本时刻新观测统一使用原位置，仅对早到片段使用预测，最多 60 秒以约束休眠外推。单点的速度为零，方差不作零置信。参数是固定工程工作点，零训练。此四臂只让运动均值改变匹配，协方差似然留作独立比较。
- 同一时刻所有报文先更新各自本地片段一次，决策和发布只看当前及过去。平面原点由首批同时可见的位置确定。共享既有 0–600 秒无标签相对平移拟合规则，原始坐标用于 0–600 秒及弃权场，600 秒之后首次可用时按两源各半的相反校正对齐，历史滤波保留原坐标、读出时应用。按 0 到末报时刻向上取整每秒发布，空刻保留。状态位置为新鲜成员最新位置的校正后均值，四臂相同。
- 新片段先有单独的系统 ID。原成员继续保持，系统 ID 的可发布年龄 60 秒、休眠记忆 600 秒。每次先让本批仍单成员的活跃片段和已建立目标或完全休眠目标竞争，每源目标一空位，各源从同一阶段前快照计算。目标代表取新鲜成员位置平均，若全休眠用最近报的成员，平均同刻并列。已有同源新鲜成员不可被替换，旧槽替换时移除旧键绑定。再将剩余的活跃单成员在不同源间配对，至少一端本批更新，接纳后保留较早系统 ID。K≥3 对源对并行生成提议，连通组若重源则全组留待处理，作为软件行为。真实 K=2 时两源子图为一次二分指派。已提交链不事后拆分，后续合并通过现有 ID 体现，历史发布保留原版。ID 并列编号只确定名称，不能决定配对。
- 只用已经到的经纬、原生时刻与源/片段等同性，速航、A-B、标签区间和参考不进入预测。同刻更新、空刻、源换序、重复报告边界和未来隔离先合成核验。所有场四臂预测以本地临时聚合前缓存冻结，随后才读 A-B，产物只存匿名聚合。前 600 秒和成熟期可并报，主分母包含全部时刻。

## 评分与终点

- 主统计单位为每个查询时刻的跨源片段对。已到且 ≤60 秒的全部本地键为共同可评分人口，A-B 同身份为真对，预测同系统为关联。以 TP/FP/FN、精度/召回/F1 及 FP+FN 为主。各因素固定另一因素做简单差，另报两差之平均与交互，以 FP 和 FN 分列避免代价混淆。独立报真边缺失、跨源错链/漏链、同源混组、唯一正确系统 ID、分裂/混并、重复、ID 换手、丢失和重获。分场和逐一剔场/组件作为描述性稳定性，空分母未定义。

- 若全体 FP+FN 下降且 FP 不增加，才标记对应工作点有保守的关联改善。若 FP 与 FN 取舍，保持两者独立，报告对应的身份连续性及成本；若固定效应符号因另一因素而变，报告交互，不用平均掩盖。该筛选无部署权重。分场、阶段、源和候选竞争计数用于追问机制。
