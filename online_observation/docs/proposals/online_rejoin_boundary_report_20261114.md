# MTAD 原接回触发报与同刻预测对照

按原 C28 逐批冻结图，对账该触发报在原接回候选的原始坐标 HOLD 门（末报坐标，≤4 km）及 KF 原代价（同刻触发原坐标和对侧预测，严格低于空配代价）。所有触发端对侧新鲜轨参与核对，逐边记录原门与原代价、前一批和当批候选资格。影子对照只把触发坐标换成原 KF 同刻批前预测，保持时钟、新鲜、其它坐标、原门及非涉事边原缓存代价，记录触发端门内、低于空配的变化及局部原缓存整组分差。影子不改实际候选，也不重求全局指派。核对 C45 当前形状的逐轨插值血缘和当批几何，报告触发坐标直接入形状的覆盖、单遮形状、单遮几何与双遮坐标的动作变化，插值括点和时间固定。报告原图用过、门因遮蔽而改变、形状直接使用、动作改变的分母。候选集从分歧期已冻结，触发报可能改变的是原接回批的刷新和排序。

在原接回时刻用同一触发实报评价四条预测路径：吸收、跳过 release 对侧轨的涉事报、跳过 retain 对侧轨的涉事报、同时跳过。每条轨从同一涉事报之前的源内 KF 状态分叉，只省对应一次坐标更新，其余原报顺序与规则相同。四轨状态、方差和配准按原时钟，全部严格早于接回批，触发及同批任何观测都不进入预测。四路径共用两候选图及同一触发实报，用原新鲜条件（60 秒）取共同支撑。每路径比较触发实报和触发自身同刻批前坐标，分别记两条触发边、另两条边、四边整组分差与增量，附名义尺度只作描述。路径差拆成遮坐标后的几何差和实报增量之差。事后按冻结匿名身份检查真边、假边、整组方向、时距和共享 A 组件。触发报受原图门与原接回选择，当前形状还可能直接复用。这里只评价固定图上未用于更新状态的触发实报，与独立后报、未选择残差或真值区分。

动作统一在原接回批。四条路径分别用整组实报方向作绝对值对照，两条极端路径各报同刻屏蔽和触发确认。单路径确认要求整组实报、整组增量、触发两边实报三者同向且非零。主动作在共同支撑下要求四条路径确认均同一方向，冲突、缺报或零分时弃权回当前形状。另与 C45 原接回批同刻屏蔽、C52 去共量、当前形状、只遮形状与双遮坐标、全弃权比较。整组与单触发边可能分向，分开读出。正方向否决原接回，负方向允许原接回。

晋级要求主动作主动保住唯一新增真命中，且至少主动纠正一次新报推错，相对当前双报及稀疏主零新增误拦，双报净收益为正、稀疏主不降，至少两个共享 A 组件有正净收益。满足后才隔离已用 A 组件冻结 MTAD 新留场，同延迟评持续 ID、稀疏长错链、原正确配对及首报。原场一次本地 CPU，零训练、选型、外部数据、新场或封存测试。无真实发布变更，证据和动作逐场冻结后连接匿名真值。`next_skill=record-experiment`。
