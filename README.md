# MTAD 研究代码

离线观测在本仓开发。在线观测使用独立仓库，两条路线各有自己的研究状态、交接和命令入口。

| 路线 | 工程入口 | 科研约定 |
|---|---|---|
| 在线观测 | [独立在线仓库](https://github.com/HKillua/assocaition-research) | [在线 AGENTS](https://github.com/HKillua/assocaition-research/blob/main/AGENTS.md) |
| 离线观测 | [offline_observation](offline_observation/README.md) | [离线 AGENTS](offline_observation/AGENTS.md) |

本仓 `online_observation/` 是拆仓时的历史快照。历史命令按原合同指定的提交和工作目录运行。原论文、MTAD 数据和本机独有证据由独立的[资料库](../biye-ronghe/README.md)维护。
