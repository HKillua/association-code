# C141 · 同源近时报文持续分离的候选切口合同

2026-11-14，READY。 [Idea 与来源](../docs/proposals/association_native_separation_candidates_20261114.md) · [执行代码](../tools/analysis/association_native_separation_candidates.py)

仅 MTAD Level1 原C92拟合侧1,748场／76组件。复用 C139 盲分区、C92旧056分数和 C151 运动缓存；以旧056 WS重放逐场校验。每个旧组及C139分歧块内每对旧组是同一三臂作用域。预先只读盘点有57,942个单组、238,952个组对，其中同源可成对的为31,664、233,431；单组最多55节点、组对最多102。各臂逐作用域两个种子槽，未提名、不可行、还原WS、重复和已在原池的候选分别记账。主对照先在逐作用域截到三臂共同实际新候选数，再在分歧块内去重且重新对齐唯一新候选数，固定各臂原排序。固定预算含空槽结果作为覆盖对照。所有臂始终包含原 C139 候选池。块外单组独立；块内重叠作用域只允许落一次完整替换。

- SCORE 取旧056阈值边际最低的同源对。OVERLAP 取原生时间包络重叠秒数最长的同源对。NATIVE 用共同时间包络内两侧时间差≤10秒的真实报文，要求两见证中点间隔30–120秒，故不能复用同一报告。每次球面距离扣50m/s×时差和两端各250m后均须为正。用符合要求的最大较小余量排序；等值按节点序。精确共用同秒位置报告的配对不提原生候选；无可靠共享谱系时只记可见证据。另计100m/s、两端各500m下合格报文对，仅作为证据敏感性。工作预算未用任何身份拟合，不视作船速或误差的实测边界。
- 相同无向最小割容量为原056超过阈值的非负边际。每个种子两端必须分开。双组两头各在一侧，且旧第二头之前的原节点必须同第一头一侧，保证原两首位。两种方向取同容量较低，平手按规范分区顺序。单组切割保留原头并计额外新头。全解逐次复算切割代价，且预固定前64个≤8节点可行切割用穷举独立核最优。三臂共用相同旧 J 和 C98 保首列表及供给证书选择实际输出，正增益才离开WS；该严格策略不会启用单组拆分。
- 各场完整候选、原生证据、作用域和实际输出先保存，再打开拟合缓存身份。安全双减需跨源 FN/FP 均减少、同源两项不增加、保原头与原代表覆盖、重复不增、原同船节点×Q毛损失为零。纯切割单列仅去假机会。安全候选数、相对原池新增安全块、分区实际旧J和安全事后上界分报，整场分别核四轴与代表、重复和支持。安全上界按每块跨源减漏和减假合计最大，额外头冲突按原块顺序保护。去最大和逐组件同口径；主匹配人口 NATIVE 相对 SCORE、OVERLAP 均须多≥10安全块、≥3个组件有净增量，且去最大后各≥5块、≥2个有净增量组件，否则结束当前种子配方。
- 公开只回传场标、匿名组件及计数，私有谱系、原生坐标和身份留服务器。零原标签、参考原档、原177、校准、V、封存、外部数据、前向和训练。一次 Campus SSH MCP CPU23–25，单线程，空CUDA，systemd Linger=yes、Restart=no，1,800秒 advisory。独立 checkout 和全新运行目录。
