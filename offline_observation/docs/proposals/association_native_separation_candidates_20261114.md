## 问题与机制

C98 的完整分区池受原 WS 和 M_BCE 并集约束，历史 MTAD 177 场仍有42个事后可同时补漏、去假且保同船供给的块。C139 检查其中一类原生时序证据在拟合侧的可用性。C141 的候选生成点改为利用**同一来源、近时且持续分离的原生报文**提示旧组内哪两条轨迹值得切开，并允许保留原候选池外的拆并方案。旧129用同源时间区间重叠挡住整组合并，保留旧组内105个工作冲突，T拒配仍丢761个有效位置点和24个目标。C78/C82 的绝对/相对距离和运动特征用于树边或已有候选打分，跨源真边与支持仍可能退化。Westendorf 等已在视觉轨迹使用同摄像机重叠互斥，实际检测下附加跨摄像机步骤没有进一步收益。这里检验的新增价值是原生持续分离能否在同一切口预算下新增**有保护的整分区机会**。 [C98](../reports/2026-11-12-association-partition-disagreement-review.md) · [旧129](../reports/2026-10-29-native-object-output-review.md) · [C82](../reports/2026-11-12-disjoint-motion-evidence-review.md) · [2026 近邻原文核读](</Users/a1/Projects/biye-ronghe/offline_observation/docs/surveys/2026-10-27_expanded_search/offline_c139_c140_sources_20261114.md>)

假设同船在两报文之间的位移受时间间隔和速度包络限制。两报告地表距离减去运动包络和两端测量误差预算得到分离余量。仅在同源两条片段有两次报文不复用、时间间隔相近的比较，且两次余量均为正时，形成工作切割种子。共用或疑似共用原生报告谱系、窗口内时钟定义不明及条件不够时，记为未确认。估计的源误差、时偏和航速尺度只作预先冻结的敏感性假设。对真实船速包络、时间差或源误差无法确认时，结果仅说明该种子对排序候选的统计用途。持续偏置和重复轨迹仍可制造假分离。

## 同预算对照

- **人口和作用域。** 限同一 MTAD Level1 C139 拟合侧1,748场／76组件，固定 151 节点、来源、原生秒、原 WS、原056/C95边分、原组首和 Q64 支持。先按原 WS 单组及已冻结 C139 分歧块涉及的原组对，建立确定性作用域。每场保留全部原节点，所有臂共用同一原组对范围和同一外部连接权限。作用域冻结后才读身份；原177、V、封存场不进入本资格检查。
- **种子与配额。** 每个作用域最多提议两个种子，均从其同源无序片段对选。SCORE 取旧分数最反对共组的对，OVERLAP 取原生时间区间重叠最长的对，NATIVE 按两次独立近时报文中的较小正分离余量排序。三臂共用源、作用域、每槽原始预算和确定性平手规则。各臂无合格种子时保留原分区槽，单列空槽和唯一候选数。再对三臂都有合格种子的作用域，固定实际启用数复算，以区分证据强度和可用率。具体时间差、两次最小间隔、航速／误差包络及任何范围上限在执行前声明。若参数依赖拟合身份，只在组件互斥的校准部分确定，评价部分不再调整。
- **完全相同的分区生成。** 对每个种子用同一确定性两端点切割，保持原作用域内旧得分和连接容量，生成一处拆分或两旧组的联合再切。给分离对相反端点只用于构造这一候选。保留原 WS、原 C98 候选和原本允许的单例。三臂分别只加各自种子候选，另留三臂候选重叠。纯拆分若没有补边空间只列去假；跨源 FN/FP 双减必须来自同一个完整拆并候选。实际选择对照用完全相同旧 J 和同一 WS 退避，事后上界与实际选择分开。

## 资格与去留

主要估计量为相对 SCORE、OVERLAP 以及原 C98，在相同作用域和匹配启用率下，NATIVE 新增的受保护双减块数。候选要求跨源 FN、FP 均严格减少，同源两项均不增加，保留原代表身份和原同船节点×Q毛支持，重复输出不增加。另列非受保护的同源真对被选作种子、有效种子覆盖、换出损失、仅去假、四轴绝对量与去最大组件结果。用一个候选实现一次整分区结果，禁止拼接各项事后最优。单位为场景和原组件；以组件计增量并做留一，不把报文或共享候选当独立样本。

一次资格尝试只在 NATIVE 相对 SCORE 与 OVERLAP **各多至少10个有保护双减块，增量至少见于3个组件，去场数最大组件后各仍多至少5块且至少2组件**时保留生成机制。若新增候选本身尚不能按同一旧 J 选到，后续先区分候选为负分和候选被有害正分压过，并单独冻结评分对照。C139 仍有事后可达机会，C141 先看较少依赖机动的同源近时报文覆盖。NATIVE 覆盖稀少、与 OVERLAP 几乎等价、增量由单一组件决定或不能保护同船支持时，结束分离种子配方。此时保留能实测的静态分区容量，转向按加入／撤出关系和源×Q供给冗余定义的完整分区偏好，采用组件隔离的同信息对照。若连静态容量也不足，下一轮先扩大合法作用域或生成动作，分开验证候选可达性和排序。

资源建议为一次 CPU 诊断，零新训练、零 GPU。候选预算与逐场最大组规模须先做只读估算，再冻结 CPU/RSS/墙时上限和审计方案。原始坐标、身份和谱系留服务器，仅回传脱敏逐场、逐组件及候选数。数据失配按一次失败保全。当前未实现或运行。
