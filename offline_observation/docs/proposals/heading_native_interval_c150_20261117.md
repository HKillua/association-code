**H1，AI／待检。** 该分支中，邻近原生位置区间方向对部分查询比原 A 更有信息；固定一种纯可见选择可产生净收益。改变的是一个完整的角度读出规则，不声称分别识别了“换来源”和“差分运算”的因果贡献。

## 唯一干预及可见规则

两臂分别为 `B_ORIGINAL` 和 `B_NEAREST_INTERVAL`。前者直接使用 C149 冻结的 C74 B，后者先逐值复制前者，只在原 `enabled_low_speed` 的组×Q 槽修改第4属性。正常求导、区间外回退、支持不足三个分支保持原值。C139 WS 成员及顺序、经纬度、速度、Q64、目标认领规则和全部有效掩码固定。不给区间替换附加新平滑、圆周合成、一致性阈值、关联修改或训练。

候选仍是 [C149 的原未复用池](../../tools/analysis/heading_fallback_fit.py)：同组**全部成员，包含首成员**；每个成员内相邻原生位置报文组成前→后区间，`0 < dt ≤ 120 s`，两端距 Q 都≤120s，按原 C149 球面距离算位移/dt≥0.5m/s。同一个 `(time, latitude, longitude)` 数值端点及重复端点对按原规则去重，保留全部供体出处。排除原 B 拟合使用的端点和当前 A 回退可能使用的保守括点。未复用只是这两类运算的字面排除，不代表与原关联、母 AIS 或其他报文统计独立。跨过 Q、全在 Q 前、全在 Q 后的区间均保留，不改变原池。

固定选取顺序：先最小化 `abs((t0 − Q) + (t1 − Q)) / 2`；并列时按原生键 `(t0,t1,lat0,lon0,lat1,lon1)` 的数值字典序，最后按冻结成员序和该成员区间行序。完全相同端点对只选一次，来源副本不增加票数。该规则不看来源身份、候选 COG、原角度或参考误差；不单独优先非首成员或某来源，也不在结果出来后换并列规则。

由选中区间的经纬度计算**球面起始方位**，作为短区间方向代理用于 Q，不称其为 Q 处真实瞬时 COG。令 φ0、φ1 为纬度弧度，Δλ 为经差的最短弧，

`E = cos(φ1) sin(Δλ)`，`N = cos(φ0) sin(φ1) − sin(φ0) cos(φ1) cos(Δλ)`，

`course = degrees(atan2(E,N)) mod 360`；若浮点舍入返回恰好360°，规范为0°。

没有候选或所选方位数值退化（`hypot(E,N) ≤ 1e−12`）时原样保留 B，不改选第二条，不减少覆盖。退化数值阈值用于方向不可定义的保护，不作为拟合参数。非法或非有限输入属于工程失败，保留现场退出，不以删点处理。实际启用掩码是“原低速分支∧存在候选∧方位非退化”，与参考值和替换前后误差无关；即使两角恰相等也算已启用，另报实际数值变化数。

选择最近单区间是最低复杂度的第一项干预。圆周合成＋模长门会改变使用的区间数、权重及拒绝条件，本轮未选，不预先宣称它能区分纯组和混组。它仅作为有新证据时重新经矩阵筛选的候选，失败后不得自动开跑。

## 估计目标、记录和判据

逐点评价 `e = abs(wrap(pred − reference))`，单位度。配对差为新−旧，负值表示改善；偏差单独定义为有符号 `wrap(pred−reference)` 的均值。主要估计在同一共同有效点和同一实际启用点上比较圆周MAE、P99以及严格>150°点数；全1,748场和去最大后的782场分别给出。P99按池内点的原 NumPy 百分位口径计算，不平均逐场P99。

| 需要同时报告的内容 | 预先固定的定义 |
|---|---|
| 全人口与启用范围 | 两臂所有组×Q、各旧分支、参考可用/不可用、共同有效、实际启用、数值改变和回退计数；四属性覆盖、代表与重复沿原评价器 |
| 平均与尾部 | 全域、全部旧低速分支、实际启用域的MAE/P95/P99、偏差、>150°数；救回=`e_old>150且e_new≤150`，新转尾相反 |
| 原非尾增害 | 只按原 `e_old≤150°` 固定人口；增害数、增害>30°/>90°数、增害/改善的角误差总量和最大增害。固定分母，不因新结果重新定义非尾 |
| 纯/混与供体 | 全域和启用域均按事后纯/混组报告；原非尾增害分别算。所选重复端点的全部出处保留，分别登记全同船、全异船及身份混合出处，不把“存在同船副本”当选取依据 |
| 时间与区间 | 跨Q定义为 `t0≤Q≤t1`（含等号），Q前为`t1<Q`，Q后为`t0>Q`；三层的真实dt、最大端点时距、中点时距、位移、位移/dt的分布；选中首/非首成员、来源与重复出处。仅解释，不分层调门 |
| 稳健性 | 每场、每组件的配对误差和/点数/尾数，所有零启用组件保留；列改善、持平、恶化组件数及最大增害。查询点不作为独立样本做显著性检验 |

**只有以下条件全通过才进入后续冻结场景验证，不能直接升级生产。** 这是开发资格判据，不是保证逐点无害或统计显著的声明。

1. 两臂分组、组序、经纬速度、查询、所有有效掩码、代表/重复及非启用航迹向逐值相同；覆盖完全相同。任一不一致判工程/协议失败。
2. 全域与实际启用域的MAE、P99、>150°点数，在全拟合及去最大两个口径上都严格下降。浮点严格下降定义为 `新−旧 < −1e−9°`，计数严格按整数；无实际启用或只有相等不通过。
3. 原非尾点的绝对角误差总量，在全拟合及去最大各自的**全部共同有效原非尾点**中，按事后纯组和混组分别不增加；以新−旧总量/该固定人口数≤1e−9度判断，空层记NA。实际启用的原非尾子集另行报告，不替换守线分母。报告所有个体增害，不要求每点都不变或都获益，也不以整体尾部收益遮蔽混组非尾净增害。
4. 去最大后至少两个有共同有效实际启用槽的组件，其组件全域共同有效点MAE按上述容差下降、>150°点数不增加；其余组件完整报告，不删负结果。

若主指标改善但第3条失败，判为存在取舍而未通过本轮资格。若纯组也不改善，只能说当前选择/方位代理缺乏净收益，不能据此断定参考字段错误或普遍排除陈旧源原因。若收益仅来自最大组件或单组件，同样不晋级。任一效果条件失败则关闭**这条冻结单区间规则**并回 Mode C；不在同次结果上加一致性门、换时距、换角度定义或挑场景续跑。若全部通过，保留开发证据，另定跨场验证与原链迁移，仍不能声称优于 TMTAFF。
