## 唯一查询命令

在仓库根目录使用 Bash 执行以下完整块。`mkdir` 拒绝已有目录；helper 的 JSON 也拒绝覆盖。它用标准库调用 nvidia-smi，最多两次各15秒的查询，不保留/占用所选 GPU，不执行训练。

```bash
(
  set -euo pipefail
  task_out=HandOver/results/GPU-POLICY-20261017-006
  mkdir "$task_out"
  git rev-parse HEAD > "$task_out/actual_commit.txt"
  date -u +%FT%TZ > "$task_out/started_at.txt"
  task_start=$(date +%s)
  task_rc=0
  timeout --signal=TERM --kill-after=5s 40s \
    /home/wangguangjie/djs/mtad-field-20261016/bin/python \
    tools/setup/gpu_allocation.py --device auto --output "$task_out/allocation.json" \
    > "$task_out/selected_uuid.txt" 2> "$task_out/query.stderr" || task_rc=$?
  printf '%s\n' "$task_rc" > "$task_out/query_exit_code.txt"
  printf '%s\n' "$(( $(date +%s) - task_start ))" > "$task_out/elapsed_seconds.txt"
  date -u +%FT%TZ > "$task_out/ended_at.txt"
  exit "$task_rc"
)
```

默认选择剩余显存最多的设备，同值时取利用率更低、编号更低的设备；默认只要求正的剩余显存，不宣称任意实验必然装得下。设备快照和候选、选中UUID、原因、进程查询结果都写入 allocation.json。进程查询失败时记录 unknown，但不因这一项误拒设备。真正启动下一任务前必须重新查询，不能把本轮快照当资源预留。
