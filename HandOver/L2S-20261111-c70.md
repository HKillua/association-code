# C70 固定候选池的全窗状态评分资格

2026-11-11，READY。来源 [C70 Idea](../docs/proposals/offline_trajectory_reselection_20261110.md)、[C71 Record/Squeeze](../docs/reports/2026-11-11-same-source-swap-review.md) 与 Mode C2.13/F311/E214。判断原生位置的时间块留出证据能否弥补旧J在固定候选池的漏选，并同时衡量完整状态。

## 固定输入和估计

原T32/12组件/2310片段，127原生事件、Q64、旧Mean输入与评价缓存，125/165/168/175输入绑定继承C71。候选是完成独审的C71 WS保首池58,975个动作及WS原分区。未重新生成、校准或按身份删选。场景秒以原Q64首末归一到[0,1]，公共局部米制坐标以最早原生观测为原点，东西方向按原点纬度缩放，处理经度环绕。相同绝对时刻的多源原生观测均保留。每个片段总权重1，每个原生位置事件权重为该片段事件数的倒数。

位置模型固定5个等间距分段线性节点，目标为加权位置平方误差加二阶差分惩罚 `0.01*D2.T@D2+1e-9 I`。无T参考选尺度。留出为场景时间的[.20,.30)、[.45,.55)、[.70,.80)三个内部块，分别拟合余下观测。每个动作只比较两组在同一批留出事件上的加权误差。每折，原组和改组中有留出点的组必须同时具备块前与块后原生观测，且全三折有非零留出权重。任一不满足均排除出两臂共同可比池，仍在总候选分母。记无留出和不能双侧支撑的数，报告可达性损失。原WS始终作为不动动作。分值为原组留出平方误差和减去改组误差和，按动作两组各折总和计算。最大正增量大于1e-3平方米才采用，同值取C71原动作顺序，没合格增量保留WS。另列同池旧J（原epsilon 1e-10）及C71不受支撑限制的原J。

最后用全窗可见位置重估同一个组模型。位置和速度由分段线性位置与米/秒斜率给出，节点处取右段斜率，末节点取最后一段。航向为斜率的圆周方向，低于0.5m/s时取同组旧Mean航向。组原生最早至最晚时间范围之外用同组旧Mean全状态。旧量测速航只用于Mean及这些输出回退，量测速度kn转换m/s一次。留出拟合与选组只使用原生位置和时间。产出固定八臂 WS Mean、WS逐片段同模型后Mean、WS组级、匹配池J组级、留出评分组级、原J组级、真组Mean和真组组级。所有32场的六个预测分组与状态先完整落盘，之后才读训练身份产生真组诊断并读取参考评价。真组与旧Mean采用同一规则。原生位置模型选型及其常数是本次工作假设。

## 验收、边界及成本

主比较留出评分对匹配J，固定原Q64和目标对应。报告真实分组同/跨源TP/FP/FN/TN、宏/加权/微统计，原C71可改场/动作保留、两类真边变化、去最大组件。物理指标为经纬度、速度、圆周航向的绝对误差和偏差、球面位置MAE/RMSE/P95/P99、漏目标/覆盖/重复、共同域及>1km新增损害。另核同分组逐片段与组级估计、真组的状态控制、回退与低速及观测域。留出分数下降只有同时改善实际关联并保持完整四属性/覆盖，才能进入下一开发验证。若可比性已经滤掉多数机会，结论归于本支撑条件。若状态模型与Mean相比明显退化，关联分数变化单独解释，整系统控制不晋级。此轮为已经开发过的T32，原候选曾使用全窗观测。零训练、零V及封存测试、零GPU。

通过SSH MCP提交独立CPU单线程科学运行及成功后独审。建议CPU17、8GiB地址空间、300秒advisory。固定checkout `association-code-run-c70` 与 `association-code-audit-c70`、前缀 `runs/LEVEL1-CONDITIONAL-TRAJECTORY-20261111` 及 `-attempt-1`、`-launch-attempt-1`、`-audit-attempt-1`、`-audit-launch-attempt-1`。科学 `python -m tools.analysis.conditional_trajectory_pilot --runs <主仓runs> --output <新输出> --time-policy advisory`，独审 `python -m tools.analysis.conditional_trajectory_audit --runs <主仓runs> --science <科学输出> --output <新独审输出> --time-policy advisory`。使用既有systemd launcher，`--max-seconds 300 --time-policy advisory`、CUDA可见为空、OMP/OPENBLAS/MKL=1，Linger=yes、Restart=no。独审核整个池、选择、保存的分组，固定抽取动作以原始事件直接重建并重算留出误差，报告抽核覆盖。参考物理指标沿统一评价器，独审不另读参考。原始预测、身份和坐标原位，回传脱敏逐场与聚合。路径冲突、绑定不合、非有限、预算或系统失败按原件保全。
